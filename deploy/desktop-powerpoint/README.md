# 在教师电脑打开 PowerPoint

网页工具栏的“打开 PPT”调用当前教师电脑上的 PowerPoint，不再先上传课件或等待逐页渲染。“切回 PPT”返回已选择的课件；连接器刚启动且未选择过文件时，切回当前活动的 PowerPoint 课件。再次选择同一路径的课件会复用现有窗口，不重置页码、笔迹或放映状态。

## 一次启动本机连接器

教师电脑需要已安装 Microsoft PowerPoint，以及带 Tk 桌面组件的现有 Python 3.10 以上版本（python.org 的常规 Windows 安装包含它）。连接器不安装依赖、Windows 服务、浏览器扩展或注册表协议，不需要管理员权限。必须在教师登录的交互桌面启动，不能作为网站服务器的后台服务运行。

在本项目检出的目录中运行：

```powershell
& .\deploy\desktop-powerpoint\Start-DesktopPowerPoint.ps1
```

如果现有 Python 不在默认位置：

```powershell
& .\deploy\desktop-powerpoint\Start-DesktopPowerPoint.ps1 -PythonExe '你的Python路径\python.exe'
```

这次登录期间启动一次即可；重复启动会提示18998端口已占用，不会结束占用者。电脑重启后再启动。排查启动错误可加 `-Foreground` 查看输出并用 Ctrl+C 停止连接器；不会自动关闭 PowerPoint。

然后回到网页点击“打开 PPT”，在 PowerPoint 自带的文件选择框选择 `.pptx` 或 `.ppt`。取消选择不会改变当前课件；若软件原未运行，取消后软件窗口会保持打开，连接器不会自动退出它。浏览器若询问是否允许网页访问本地网络，需要教师确认允许；连接器不会修改浏览器安全设置。远程网站使用者必须在自己的电脑启动连接器，不会打开网站服务器的 PowerPoint。

## 圆形悬浮球与实时小窗

启动教师端连接器后，桌面右下角出现 48 个逻辑像素的紧凑悬浮球：白色圆底、应用图标和轻微悬停反馈，不显示额外文字。实时小窗从球体上方展开；也可由网页的圆形 PPT 图标召回。拖动球体只改变位置；贴边保留 8 个逻辑像素的安全间距，整个球体限制在屏幕工作区内。拖动时收起预览，松开后可继续拖动。右键可以选择预览目标、重新绑定窗口或隐藏。

1. 在 WebGIS 中点击 **桌面悬浮球的 PPT 图标**，先显示当前 PowerPoint 窗口的实时预览。
2. 点击小窗里的 **放大进入 PowerPoint**，进入原来的 PowerPoint 窗口。已有放映继续使用，不从第一页重新开始；编辑窗口则最大化。
3. 球体随之换成 **WebGIS Logo**。点击它预览网页，再点 **放大进入 WebGIS** 返回原浏览器窗口。
4. 点击“收起”或按 Esc 只关闭预览，不关闭、保存或重排原应用窗口。

小窗使用 Windows 自身的窗口缩略图：不会重新解析或上传 PPT，也不把桌面画面发给网站。预览不能直接编辑课件。原窗口最小化时，Windows 可能暂停更新缩略图，界面会提示；点放大可恢复原窗口。无法生成预览时会明确说明，仍可进入原应用。

切换优先使用已经打开的 PowerPoint 窗口，不依赖 Office 自动化连接来判断软件是否存在。多个窗口且尚未选择时，由教师选择一次；随后跟随最近使用的课件或放映。只有 PowerPoint 未运行且没有主窗口时才启动软件起始页，不反复要求选文件。Office 正在启动或被提示框阻挡时不会再启动另一份。

“打开 PPT”保留显式选择新课件的入口；“切回 PPT”继续返回该入口选定的课件。日常往返请使用悬浮球，无需重复点击“打开 PPT”。

请在 Edge、Chrome、Firefox、Brave 或 Opera 的独立窗口显示 WebGIS，保持网页标签可见。只有一个匹配窗口时自动使用；有多个时由教师选择。已关闭或换成其他网页的窗口会要求重选。没有找到网页时，小窗提供“用独立浏览器打开 WebGIS”，仅在明确点击后打开固定正式网址，不自动登录。Codex 侧边网页不属于独立教师浏览器窗口。

球体显示和拖动不会主动抢占放映焦点；点击才展开预览。通过任务栏或 Alt+Tab 选中球体后，可按 Enter / 空格展开。位置限制在屏幕工作区域，退出连接器后不保存窗口句柄或位置。Windows 若拒绝前台切换，会提示使用任务栏；只有核实进入目标窗口后才自动切换球体图标。

## 保留的功能和边界

- “页面预览 PPT”仍提供原有逐页预览和网页笔迹；只有明确选择这一入口才触发渲染。
- PowerPoint 中的编辑、笔迹和网页预览笔迹相互独立。连接器不会自动保存、关闭原课件，也不会把桌面 PowerPoint 画面自动写入课堂截图或报告。
- 地图、课堂计时和记录照常运行；在 PowerPoint 与地图之间可用悬浮球、Windows 任务栏或 Alt+Tab 切换。
- Office 的信任、保护视图、修复或授权提示需教师自行处理，不自动接受、关闭或绕过。程序化打开期间遵循已有信任中心策略，已有ForceDisable策略保持，结束后恢复先前自动化模式，不修改信任中心设置。Windows 若拒绝前台切换，页面会明确提示点击任务栏，不能将“请求已发送”视为已经切换成功。
- 默认允许本项目的 `https://webgisai.com`、`https://www.webgisai.com` 和本机5173/18080页面。自定义站点须由部署者在启动 Python 模块时明确传入 `--origin`，不使用通配来源。

## 本机边界

连接器固定绑定127.0.0.1:18998。它不读取项目配置、登录 cookie、模型密钥、认证数据库或教学数据；浏览器不能提交路径、读取文件、上传课件或指定其他可执行程序。操作请求使用本次连接器进程生成的随机校验值，严格校验 Origin/Host，拒绝代理请求。路径只由本机文件选择框引入，网页仅显示文件名和操作状态。

更新时重启新版本机连接器，已打开的 PowerPoint 和课堂数据无需重开。新版网页遇到旧连接器会说明悬浮球需要更新，原“打开 PPT／切回 PPT”仍兼容。回退时恢复原前端和对应连接器代码。停止连接器不影响地图后端或已打开的 PowerPoint；不需要还原课堂数据。
