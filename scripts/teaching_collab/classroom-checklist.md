# 《人口分布》课堂验收清单

每轮记录：日期、客户端、分支、SHA、preview manifest、隔离项目和课堂ID、浏览器及分辨率。保存操作步骤、截图索引、实际行为、预期和未通过原因。老师操作耗时与正式教学时间分开。

| 环节 | 教学检查 | 网页证据 |
| --- | --- | --- |
| 课前设计 | 目标、学情、问题链与40分钟活动一致；接受的教案用于本次开课 | 设计、接受、预演、开课及快照一致 |
| 上海导入 | 描述分布并提出问题，保留学生观察 | 地图定位、图例与材料可见 |
| 概念辨析 | 人口总量不等于密度；灯光不是人口直接测量 | 指标、年份、来源及提示 |
| 上海比较 | 区级均值不代表区内均匀，数量与比例区分 | 黄浦/崇明对照、提问与分层提示 |
| 上海验证 | 局部影像非全区代表，不从景观直接确证某年人口 | 局部位置对照、返回全市、影像日期限制 |
| 中国绘线 | 学生先画线说明依据，不提前呈现标准答案 | 画笔、截图、初始图层状态 |
| 中国解释 | 胡线、降水、河谷/水源和人为因素有条件解释 | 图层开关、图例及区域反例 |
| 世界迁移 | 用新区域检验解释，而非背诵稠密区 | 世界人口资料、尺度切换和迁移追问 |
| 学生总结 | 用具体证据修正原判断，保留未解决问题 | 总结题、截图与课后任务 |
| 课后复盘 | 报告忠实还原事件，未采集不计算参与/正确率 | 本课堂报告、截图回看和建议来源 |

每轮还要检查：图层加载失败原因、刷新恢复、助教等待与回退、语音授权与尾句（有真实麦克风才验证）、课堂中断后恢复；深浅主题、1920×1080和1366×768下的文本可读性、面板遮挡及按钮可点击性。三维地球、TOP20、健康端点、课堂报告保留。

每个问题报告模板：

```text
问题ID（稳定，不因未改善换名）：
课堂环节与目标：
前置条件及实际复现步骤：
对教师和学生的影响：
现有证据路径：
建议与对应参考来源（资料参考/实际体验）：
准确文件路径与范围：
可观察的验收动作：
修复前 / 修复后：
结论 improved / unchanged / regressed：
未验证项及原因：
```

参考基线：[飞象老师](https://www.feixianglaoshi.com/h5/)用于互动教学资源；[MapMaker](https://www.esri.com/en-us/industries/k-12-education/mapmaker)用于地图探究。未经实际操作不宣称竞品实测，更不能将两款AI的认可当成人类课堂效果证明。
