# 专业教学智能体使用范例 —— 以《中国人口分布》示范课为脚本

> 当前实现核对日期：2026-09-12。智能体通过 `teaching_context` 知道当前课时、班课、环节和阶段，并按课前、课中、课后采用不同回答策略。只有班课正在进行且请求携带有效 session 时，完成的问答才写入 `assistant_exchange` 事件并进入课后报告。`record_observation` 用于记录学情；`launch_question` 只在教师课堂工作台呈现口头提问并记录证据，不向学生端或投屏发布。
>
> 所有标 ✅ 的范例在当前代码上可直接演示；标 🔜 的是已规划待实现项（附依赖），保留在文中作为路线图。

---

## 0. 阅读说明

**教学上下文自动携带。** 教师通过底部「教案设计」「课堂模式」「教学复盘」进入对应工作流后，系统维护当前的课时（lesson）、班课（session）、环节（stage）与阶段（phase：备课 course_prep / 上课 in_class / 复盘 post_class），并随智能体对话发往后端。上下文有效时，教师不需要重复说明“我正在上课”或“现在是第几环节”。

**三段教学契约。** 每次教学回答固定附带结构化的"教学处理"三段：

- **证据或观察点**：只引用当前地图上真实存在的图层、选区、素材或视觉读图结果；没有证据时明确写"本回答缺少当前地图或素材证据"，不编造。
- **给学生的问题**：1–2 个可直接由教师口头提出的问题。
- **教师收束语或下一步**。

**风险分级与确认卡。** 智能体的每个地图/课堂操作都有风险级：low/medium（切图层、查数据、记学情、在教师工作台呈现口头提问等可逆或影响可控的操作）直接执行；high（当前包括消耗 API 余额的图片生成、结束班课）必须弹确认卡，教师点「确认执行」才真正执行，15 分钟未确认自动过期；点「拒绝计划」后同类操作在本会话内不再自动发起。

**按阶段差异化。** 同一个问题在不同阶段得到不同形态的回答：

| 阶段 | 回答策略 | 检索策略 |
|---|---|---|
| 课前 course_prep | 允许长篇结构化输出（问题阶梯、证据路线、预演话术），问题附预期答案与常见误区 | 本地知识库 + 在线检索 |
| 课中 in_class | ≤150 字，第一句可直接口播，最多 1 个追问，不展开综述 | **跳过在线检索**（延迟优先） |
| 课后 post_class | 无明确指令时默认进入复盘轨道；必须引用课堂真实记录的具体数字，记录之外不得编造 | 本地知识库 + 在线检索 |

**可见的智能体。** 悬浮窗内每条回复带意图徽标（讲解 / 追问 / 操作 / 复盘 / 知识）；执行过工具的回复可展开「工具调用」轨迹查看每个工具名与风险级；能力芯片已收敛为「图片生成」一项一键发送，读图 / 追问 / 复盘 / 切换底图等入口分别并入课堂对话流、教学复盘与教案设计。

**范例格式。** 每个范例四栏：**教师输入（原话）→ 智能体内部发生什么 → 教师看到什么 → 对课堂的实际作用**。

## 1. 课前 · 备课

| 编号 | 范例 | 状态 |

| A3 | 问题阶梯细化 | ✅ |
| A4 | 场景预览 | ✅ |
| A5 | 预演检查与模拟测试 | ✅ |

### A1 · 备课生成 ✅

**教师输入**

> 帮我备一节《人口分布》课，高一，40 分钟，重点讲胡焕庸线，最后想用上海做城市案例。

**智能体内部发生什么**：在“共创教案”创建 lesson-design session，教师输入完整要求后点击「生成完整初稿」。服务解析课题、年级、时长、重点与活动要求，一轮预填多个尚未确认的章节；已有内容和已确认章节不会被覆盖。MiniMax 不可用时走规则草稿，并明确标注仍需教师核对。

**教师看到什么**：工作台出现整份待确认初稿，并显示“刚修改、还缺、下一步确认”。教师可点「一键智能优化」整份提升，点「采用当前建议并继续」逐步确认，或在输入框写要求后点「只修改当前环节」。最后仍需完成题目匹配、能力绑定和预演检查。

**对课堂的实际作用**：教师从空白页起草转为审核一份有明确缺口提示的初稿，同时保留逐段共创和直接编辑能力；任何 AI 建议都不会绕过教师确认成为正式课时。

### A2 · AI 导入教案 ✅

**教师输入**：课前面板 →「AI 导入教案」→ 粘贴整篇教案文本（如《人口分布 40 分钟融合教案》）。

**内部**：`lesson_import` 异步 job 用 LLM 把自由文本解析为结构化 stages/questions/scenes（LLM 不可用时规则兜底），任务面板可见进度。

**教师看到**：课时列表出现新课时，8 个环节带时长、题目与场景骨架；可逐环节「存当前地图为场景」补齐地图状态。

**作用**：存量 Word 教案十分钟变成可上课的结构化课时，是三阶段闭环的入口。

### A3 · 问题阶梯细化 ✅

**教师输入**（课前面板打开，phase=course_prep）

> 为胡焕庸线环节再设计三个由浅入深的追问，每题给出预期答案要点和学生常见误区。

**内部**：关键词「设计…追问」→ `teaching_question` 意图；course_prep 阶段策略解锁长篇结构化输出，prompt 要求"由浅入深：观察描述 → 比较分析 → 解释迁移，并附常见误区"。

**教师看到**：三级问题阶梯（每题附预期要点 + 误区标签）+ 教学契约三段。当前版本需教师把满意的追问手动整理进教案；自动生成修改 diff 并写回教案仍是 C3 🔜。

**作用**：把"临场想追问"变成"课前备好的阶梯"，误区标注直接对应课中的学情速记标签。

### A4 · 场景预览 ✅

**教师输入**：课前面板选中环节 s4 →「预览场景」。

**内部**：`apply_stage_scene` 纯本地同步执行（无 LLM）：切换底图、开关图层、应用 `hu_line_comparison` 模板、恢复视角。

**教师看到**：地图瞬间进入"胡焕庸线两侧差异"预设画面——经典线与动态拟合线叠加、省界与人口密度就位。

**作用**：备课时就能验证"上课那一刻学生看到什么"，杜绝课上现调图层。

### A5 · 预演检查与模拟测试 ✅

**教师输入**：在教案设计第八步点击「运行完整预演」；确认发布后，还可进入独立“模拟测试”。

**内部**：教案设计检查读取同一 design revision，确定性核对必填章节、总时长、题目答案、场景模板、图层和数据引用，不调用模型替代事实校验。独立模拟测试使用课时工作副本，可逐环节预览场景、调整时长和题目，并记录检查结果；未完成或失败项会阻止冒充“可上课”。

**教师看到**：就绪项、阻断项和建议项，以及与当前 revision 绑定的报告。草稿发生变化后，旧报告不再作为通过依据；模拟测试可完成、取消或返回继续修改。

**作用**：把“教案文字看起来完整”和“系统资产真实可执行”分开核验，避免课堂上才发现图层、题目或时长不可用。

### A6 · 备课资料检索 ✅

**教师输入**：打开「数据库」→「查找新资料」，搜索“胡焕庸线”。

**内部**：资源搜索服务合并本地知识库、已保存素材和权威联网入口；配置外部搜索端点时会补充经过域名白名单过滤的在线结果。

**教师看到**：资料入口与简述，可选择「保存为素材」或「导入本课时」。内置权威入口只是继续核对资料的入口，不代表某个最新数字已被验证。

**作用**：备课资料留在系统里，课中经 `open_material` 一句话调出。

## 2. 课中 · 上课

| 编号 | 范例 | 状态 |
|---|---|---|
| B1 | 读图讲解（截图 + 视觉模型） | ✅ |
| B2 | 教学动作（操作后必附教学解释） | ✅ |
| B3 | TOP20 可视化查询 | ✅ |
| B4 | 课堂对话追问 | ✅ |
| B5 | 教师工作台口头提问 | ✅ |
| B6 | 误区记录（对话 + 面板双路） | ✅ |
| B7 | 票数讲评（仅使用真实采集数据） | ◐ 需外部真实作答数据 |
| B8 | 阶段提示卡 | 🔜 需 stage_prep 缓存 |

### B1 · 读图讲解 ✅

**教师操作与输入**（s4 环节，胡焕庸线对比场景在屏）：先点顶部「截图」选择地图区域并保存，在图片库对该图点「加入智能助教」，再输入：

> 结合当前画面讲解胡焕庸线两侧的人口差异。

**内部**：图片以 `image_attachment` 随请求发送，`teaching_explain` + map_reading 分类命中 → 视觉模型读图 → in_class 策略压缩到可口播长度。未配置或未成功调用视觉模型时只使用结构化地图上下文并明确说明，不能声称已读取图片像素。

**教师看到**：一句可直接口播的结论 + 教学契约三段，证据栏引用画面里真实的线与图层；本次问答同时记入班课事件流。

**作用**：教师站在讲台上 5 秒内拿到"贴着当前画面"的讲解词，而不是一段百科综述。

### B2 · 教学动作 ✅

**教师输入**：「打开人口密度图层，视角切回全国。」

**内部**：`teaching_action` → 规划 `toggle_layer` + `set_view`（均低风险，直接执行）→ 执行后强制追加教学解释与三段契约。

**教师看到**：地图完成动作；回复含"图层已显示/视角已更新" + 工具调用轨迹 + 教学契约（此时的"给学生的问题"正好用来衔接："打开密度图后，先请学生找最深色的三个省"）。

**作用**：地图操作不再打断教学话术——每次操作自带下一句课堂语言。

### B3 · TOP20 可视化查询 ✅

**教师输入**（s3 数据探究环节）

> 标出 2020 年人口最多的 20 个地级市。

**内部**：规划并执行 `run_visual_query`（medium 风险），生成高亮图层和排名数据；参数、指标和年份由查询结果明确返回。

**教师看到**：TOP20 城市高亮 + 排名弹窗（柱状图），回复附教学契约——追问正是预设的"为什么集中在东南侧"。

**作用**：课前场景与课中对话触发的是同一个查询能力，教师随口一句话即可复现备课时的数据画面。

### B4 · 课堂对话追问 ✅

**教师输入**（文本或语音）：

> 根据当前地图提出一个追问，引导学生从气候、地形、水源三方面解释胡焕庸线两侧的人口差异。

**内部**：`teaching_question` 路由自动携带当前 lesson/session/stage/phase；in_class 策略保持短回复并跳过在线检索，问答写入 `assistant_exchange` 事件。

**教师看到**：智能体给出可口播的追问、预期答案方向和收束语。当前界面没有独立「AI 追问」或「复制问题」按钮，教师应直接口头使用，或把需要记录的临时问题填入课堂面板的「记录并提问」。

**作用**：追问贴合当前环节与地图上下文，并自动进入课后报告的智能体使用记录；是否正式记录为课堂题目仍由教师决定。

### B5 · 教师工作台口头提问 ✅

**场景**：s3 环节，TOP20 城市已经高亮，教师希望马上组织一次口头讨论。

**教师输入**

> 现场提问：为什么这些人口大城几乎都在胡焕庸线东南侧？选项是“自然与经济条件叠加”或“纯属历史巧合”。

**智能体内部发生什么**

1. 课堂动作规划器产出 `launch_question{text, options, answer_index}`；
2. 执行器确认存在进行中的班课，再以 medium 风险直接执行；
3. 题目写入当前班课事件流，delivery 为教师口头组织，不进入投屏，也不发送到学生手机；
4. 当前没有独立学生登录端，系统不会声称已经向全班发布或收集到作答。

**教师看到什么**：教师课堂工作台出现题干和选项，可直接口头提问并依据现场回答记录“答对、部分、误区”。工具轨迹显示 `launch_question（medium）`，不会出现“向学生端发送成功”或虚构票数。

**对课堂的实际作用**：智能体把临场问题整理并记入课堂证据，但实际提问、点名和判断仍由教师完成。若需要使用课堂面板中明确配置的投屏题或学生作答数据，应分别核对 delivery 和真实采集状态，不能把口头提问当成学生端发布。

### B6 · 误区记录 ✅

**教师输入**（学生答"东部人多是因为东部发达"之后）

> 记一下：有学生把人口分布归因于单一经济因素，是"单因归因"误区。

**内部**：「记一下」命中动作词表 → `teaching_action` → `record_observation{verdict: 误区, tag: 单因归因, note: …}`（medium，直接执行）→ 校验存在进行中的班课（没有则明确提示"该操作需要正在进行的班课，请先在课中面板开始上课"）→ 写入 `teacher_observation` 事件。verdict 支持中文同义词（答对/正确 → correct，部分 → partial，误区/错误 → misconception）。

**教师看到**：「已记录课堂学情（存在误区）：有学生把人口分布归因于单一经济因素」。课中面板的学情速记（答对/部分/误区 + 误区标签芯片）依然可用——两条路写入同一事件流。

**作用**：教师不必中断讲课伸手点面板，一句话就把学情落进课后报告的误区统计。

### B7 · 票数讲评 ◐（仅在真实作答已进入 session 时）

当前仓库没有独立学生登录或作答提交入口；只有受信任的外部采集链路已经把真实 responses 写入当前 session 时，才可演示本节。没有真实作答时应改用 B6 的教师观察，并明确显示“未采集”。

**教师输入**（条件示例：外部链路已真实采集 s1q1 的 28 份作答，投票已关闭）

> 点评一下刚才的投票结果。

**内部**：只有 session 中确有 responses 时，in_class 阶段才注入课堂轻量简报（最近一题的选项票数、正确率和已记录误区）；没有 responses 时不得生成票数或正确率。

**教师看到**：引用真实票数的点评——"68% 的同学已经建立了'东南密、西北疏'的格局认知；选'均匀'的 8 位同学值得追问：他们看到的可能是城市点位而不是密度分布"+ 1 个现成追问。

**作用**：在真实采集链路存在时，讲评词可以贴着本班真实分布；当前仓库单独运行时，这一能力只能验证报告对已有数据的处理，不能声称已完成学生端闭环。

### B8 · 阶段提示卡 🔜（需 stage_prep 缓存）

规划行为：进入环节时侧栏静默出现"本环节目标 + 建议图层顺序 + 第一问 + 收束语"，来自教案静态数据与后台预取缓存，教师不点就等于不存在。

## 3. 课后 · 复盘

| 编号 | 范例 | 状态 |
|---|---|---|
| C1 | 生成课后报告 | ✅ |
| C2 | 复盘追问（真实数据注入） | ✅ |
| C3 | 改进写回下一课时教案 | 🔜 需 lesson patch + diff 确认 |
| C4 | 证据链定格 | ◐ 部分可跑 |

### C1 · 生成课后报告 ✅

**教师输入**：下课后点击「教学复盘」，选择课堂记录，再点「生成课堂报告」。

**内部**：报告 job 聚合真实事件流：环节计划/实际用时对比、逐题票数与正确率、教师观察与误区标签统计、快照数和班课进行期间的智能体使用次数；LLM 生成学情诊断（不可用时规则兜底并标注）。

**教师看到**：报告面板 + 可下载 Markdown；诊断按「学情诊断 / 共性误区分析 / 下节课教学建议」三节，引用具体数字。

**作用**：课堂的每一次提问、观察、智能体求助都进了同一本账。

### C2 · 复盘追问（真实数据注入） ✅

**场景**：课堂已结束，教师打开「教学复盘」（phase=post_class）。以下数字只是假设 session 已经真实采集到对应作答时的格式示例；没有作答时，系统必须回答“课堂记录中没有这一项”。

**教师输入**

> 这节课学生哪道题错得最多？可能是什么原因？

**智能体内部发生什么**

1. post_class 阶段的普通问题**默认路由到复盘轨道**（`teaching_reflect`）——教师不必说"复盘"这个词；
2. 请求携带的 session 句柄触发**课堂真实记录注入**：环节用时、逐题票数与正确率、误区标签计数、参与人数、智能体使用次数，压缩为摘要进入 prompt；
3. 复盘约束升级为"**必须引用课堂真实记录中的具体数字，记录之外的学生表现一律不得推断或编造**"——有据可引时贴数据说话，没有对应记录的问题明确说"课堂记录中没有这一项"。

**教师看到什么**

> 错误率最高的是概念建构环节的密度比较题：28 人作答，正确率 46%，13 人选了"甲区域人口密度更高"——正对应教案预设的「混淆数量与密度」误区，你课上也为该标签手动记了 3 次。原因判断：学生在用人口总量直接比疏密；该题出现在概念讲解后仅 1 分钟，铺垫偏短（s2 实际用时 6.5 分钟，计划 4 分钟，超时主要耗在这道题的讨论上）。
>
> 教学处理：
> - 证据或观察点：s2q2 正确率 46%（13/28 误选）；误区「混淆数量与密度」记录 3 次；s2 超时 2.5 分钟。
> - 给学生的问题（下节课导入用）：北京约 2189 万人、1.64 万 km²；上海约 2487 万人、0.63 万 km²——谁更"挤"？说出计算依据。
> - 教师收束语或下一步：下节课用一道真实城市对比题先重测密度概念，再进入新课。

**对课堂的实际作用**：复盘不再靠回忆——每个判断都能点回真实票数与记录；"没有记录不编造"从一句免责声明变成有牙齿的约束（有记录时它反过来强制引用数字）。

### C3 · 改进写回教案 🔜（需 lesson patch + diff 确认）

规划行为：教师接着说"把这些改进点写进下节课教案"→ 生成教案修改 diff 卡（如：下一课时导入新增密度检测题、调整环节时长）→ 教师确认后写回并记录来源 session——课后闭环回课前。

### C4 · 证据链定格 ◐

**教师输入**：「把今天的结论整理成一段可以直接抄在笔记上的课堂小结。」课中可直接在助教对话中发送；课后提问则由复盘轨道基于真实记录生成。报告已含快照统计；把截图与结论装订成图文小结属后续增强。

## 4. 附录

### 4.1 能力边界（智能体明确不做的事）

- 不在无确认的情况下执行高风险操作（`generate_image` 消耗 API 余额、`end_class_session` 结束班课均需教师确认）；`launch_question` 只在教师课堂工作台呈现口头提问，不向学生端发布内容；
- 不编造图层、数据或学生表现：无地图证据必须声明；复盘只引用真实事件流，post_class 缺记录时明说；
- 不读写文件、不执行命令、不做重型 GIS 分析（PyQGIS 工作流走独立的 /workflow 管线）；
- 不在课中做长篇综述或在线检索（延迟优先，深度内容留给课前/课后）；
- 没有进行中的班课时拒绝课堂写入操作，并提示先开课。
