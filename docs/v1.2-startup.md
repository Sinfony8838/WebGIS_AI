# WebGIS-AI 启动说明

本文档面向当前 WebGIS-AI 课堂系统，说明本地启动、环境变量和发布前验证步骤。

## 1. 先决条件

| 组件 | 建议版本 | 说明 |
|---|---:|---|
| Python | 3.10+，推荐 3.12 | 运行 FastAPI 后端 |
| Node.js | 18+ | 运行 Vite 前端 |
| PowerShell | 5.1+ | Windows 一键启动脚本使用 |

## 2. 快速启动

```powershell
.\start_webgis_ai.cmd -InstallIfMissing -OpenBrowser
```

如果默认 Python 路径不对：

```powershell
.\start_webgis_ai.cmd -PythonExe "C:\Users\zcyxn\AppData\Local\Programs\Python\Python312\python.exe" -InstallIfMissing -OpenBrowser
```

启动后默认访问：

```text
http://127.0.0.1:5173
```

## 3. 手动启动

后端：

```powershell
python -m pip install -r requirements.txt
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 18999
```

前端：

```powershell
cd frontend
npm install
npm run dev
```

## 4. 常用环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `WEBGIS_AI_HOST` | `127.0.0.1` | 后端监听地址 |
| `WEBGIS_AI_PORT` | `18999` | 后端端口 |
| `WEBGIS_AI_AUTH_TOKEN` | 空 | 公网部署必须设置，作为后端访问令牌 |
| `WEBGIS_AI_CORS_ALLOW_ORIGINS` | `http://127.0.0.1:5173,http://localhost:5173` | 公网部署时改为真实前端域名 |
| `WEBGIS_AI_AMAP_WEB_SERVICE_KEY` | 空 | 高德 POI 在线检索 key |
| `WEBGIS_AI_DEFAULT_BASEMAP` | `amap_vector` | 默认底图 |
| `WEBGIS_AI_MINIMAX_API_KEY` | 空 | MiniMax 智能助教 key |
| `WEBGIS_AI_MINIMAX_BASE_URL` | `https://api.minimax.io/v1` | MiniMax API endpoint |
| `WEBGIS_AI_MINIMAX_MODEL` | `MiniMax-M2.5` | MiniMax 模型名 |
| `VITE_API_BASE_URL` | `http://127.0.0.1:18999` | 前端构建时使用的后端地址 |

公网部署示例：

```powershell
$env:WEBGIS_AI_AUTH_TOKEN="请生成至少32位随机访问令牌"
$env:WEBGIS_AI_CORS_ALLOW_ORIGINS="https://webgis.example.edu"
$env:WEBGIS_AI_AMAP_WEB_SERVICE_KEY="请填入高德Web服务Key"
$env:WEBGIS_AI_MINIMAX_API_KEY="请填入MiniMax Key"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18999
```

前端构建示例：

```powershell
cd frontend
$env:VITE_API_BASE_URL="https://api.webgis.example.edu"
npm install
npm run build
```

## 5. 访问令牌

后端设置 `WEBGIS_AI_AUTH_TOKEN` 后，前端初始化失败时会显示访问令牌输入框。输入与后端一致的令牌并保存即可继续使用。

也可以在浏览器控制台手动写入：

```javascript
localStorage.setItem("webgis_ai_api_token", "请填入访问令牌");
location.reload();
```

## 6. 验证命令

后端测试：

```powershell
python -m unittest discover backend/tests
```

前端测试与构建：

```powershell
cd frontend
npm test
npm run build
```

接口自检：

```powershell
curl http://127.0.0.1:18999/health
curl -H "Authorization: Bearer 请填入访问令牌" http://127.0.0.1:18999/health
```
