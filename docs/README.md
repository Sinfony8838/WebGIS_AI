# 文档索引与维护边界

本目录只把可公开、可复现且需要随代码同步维护的说明纳入 Git。运行数据、私有课件、账号信息和本机专用材料继续由 `.gitignore` 排除。

## 当前使用说明

- [`../README.md`](../README.md)：项目入口、能力概览、启动方式、常用配置和关键接口。
- [`../PROJECT_DESCRIPTION.md`](../PROJECT_DESCRIPTION.md)：当前产品定位、架构、能力和边界。
- [`../项目设计要求/项目定位要求.md`](../项目设计要求/项目定位要求.md)：当前阶段不可突破的产品与课程范围约束。
- [`上线配置与安全核查.md`](上线配置与安全核查.md)：本地启动与公网部署配置、安全边界和验证步骤。
- [`knowledge_base_ingest.md`](knowledge_base_ingest.md)：知识库权限、检索、写入、删除和资料接地说明。
- [`当前功能说明与课程融合方案.md`](当前功能说明与课程融合方案.md)：面向教师与专家的当前功能、课程融合方式和能力边界。
- [`智能体使用范例_人口分布.md`](智能体使用范例_人口分布.md)：当前教学智能体在人口专题中的可执行范例。
- [`人口分布_40分钟全流程产品演示脚本_0902.md`](人口分布_40分钟全流程产品演示脚本_0902.md)：课前、课中、课后完整演示脚本。
- [`../AGENT_HARNESS.md`](../AGENT_HARNESS.md)：统一 Agent Harness 的实现边界。

配置时可参考仓库根目录的 [`.env.example`](../.env.example)；它覆盖常用配置，完整说明见[上线配置与安全核查](上线配置与安全核查.md)。当前启动器和后端不会自动加载根目录 `.env`：后端变量写入进程或用户环境，前端 `VITE_*` 写入不提交的 `frontend/.env.local` 或在构建前设置。示例只含空值或公开默认值，真实密钥不得提交。

## QA 与历史记录

- `docs/qa/` 和仓库根目录 `audit/` 中带日期、分支或基线提交的文件是当次验证快照。它们用于保留证据，不自动代表后续提交仍完成相同的运行时验收。
- [`../INTEGRATION_REVIEW.md`](../INTEGRATION_REVIEW.md) 是 2026-09-08 的历史集成复验记录，不是当前发布状态页。
- [`../INTERACTION_AUDIT.md`](../INTERACTION_AUDIT.md)、[`../BRANCH_INVENTORY.md`](../BRANCH_INVENTORY.md) 和 [`../HANDOFF-choropleth-replay.md`](../HANDOFF-choropleth-replay.md) 也是带基线的历史审计或交接材料，不是当前功能清单。

## 维护规则

行为或默认配置发生变化时，同一 PR 应同步更新对应入口文档。代码是行为事实来源；文档中的“已实现”“已验收”和“当前默认”必须分别有源码、自动化测试或当次运行证据支持。
