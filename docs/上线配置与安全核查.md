# WebGIS-AI 上线配置与安全核查

本文档面向协助发布的老师，按 2026-09-12 当前代码实现整理。发布前请优先参考本文档，并把仓库根目录的 `.env.example` 作为常用配置示例，不要在文档或 Git 中保存真实密钥。当前启动器和后端不会自动读取仓库根目录 `.env`；后端变量必须进入进程或用户环境，前端 `VITE_*` 应在构建前设置或写入不提交的 `frontend/.env.local`。

## 1. 项目架构

- 前端：React + TypeScript + Vite + Cesium + OpenLayers，目录为 `frontend/`。
- 后端：FastAPI，入口为 `backend/app/main.py`。
- 本地运行数据：`backend/data/` 下的 `state/`、`uploads/`、`outputs/`、`workflows/`、`auth/`、`voice-models/` 属于运行产物，不应提交到 GitHub。
- 内置教学数据：`backend/app/data/builtin/`，属于代码随包资源。
- 默认访问地址：前端 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:18999`。

## 2. 必要运行环境

- Python 3.10 及以上，建议 Python 3.12。仓库一键启动器会拒绝 3.10 以下解释器。
- Node.js 22 及以上。当前锁文件中的 Cesium 依赖声明要求 Node.js 22+，一键启动器会拒绝更低版本。
- 可访问在线地图瓦片服务的网络环境。

## 3. 后端配置

生产或课堂发布时，建议通过系统环境变量配置，不要把真实 key 写入代码、文档或 `.env` 后提交。

| 变量名 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `WEBGIS_AI_HOST` | 否 | `127.0.0.1` | 后端监听地址。课堂本机演示保持默认；局域网访问才考虑改为 `0.0.0.0`。 |
| `WEBGIS_AI_PORT` | 否 | `18999` | 后端端口。 |
| `WEBGIS_AI_AUTH_MODE` | 否 | `users` | 鉴权模式：`users`（默认，多用户邮箱密码登录）、`legacy_token`（单访问令牌兼容模式）或 `disabled`。 |
| `WEBGIS_AI_REGISTRATION_MODE` | 否 | `approval` | 教师注册策略：`closed` 关闭公开入口，`approval` 提交后等待管理员审核，`open` 立即创建教师账号；公网保持 `approval` 或改为 `closed`。 |
| `WEBGIS_AI_AUTH_DB` | 否 | `backend/data/auth/auth.db` | 鉴权 SQLite 数据库路径（用户、会话与审计日志）。 |
| `WEBGIS_AI_BOOTSTRAP_KEY` | 按部署 | 空 | `users` 模式下非本机首次初始化管理员时必须提供。 |
| `WEBGIS_AI_AUTH_TOKEN` | legacy 模式必填 | 空 | 单访问令牌。仅在 `WEBGIS_AI_AUTH_MODE=legacy_token` 时生效；默认 `users` 模式使用会话登录，不读取该变量。 |
| `WEBGIS_AI_COOKIE_SECURE` | 否 | `false` | HTTPS 部署时设为 `true`，会话 Cookie 仅经 HTTPS 传输。 |
| `WEBGIS_AI_SESSION_IDLE_MINUTES` | 否 | `480` | 会话空闲有效期（分钟）。 |
| `WEBGIS_AI_SESSION_MAX_HOURS` | 否 | `24` | 会话绝对有效期（小时）。 |
| `WEBGIS_AI_AUTH_EXEMPT_PATHS` | 否 | 空 | 仅在 `legacy_token` 模式生效的免鉴权路径，逗号分隔。它不能改变默认 `users` 模式下的公开路径。 |
| `WEBGIS_AI_TRUST_PROXY_HEADERS` | 否 | `false` | 是否信任 `CF-Connecting-IP`。仅在可信代理会覆盖该头时设为 `true`，否则客户端可伪造来源地址。 |
| `WEBGIS_AI_CORS_ALLOW_ORIGINS` | 公网必填 | `http://127.0.0.1:5173,http://localhost:5173` | 允许访问后端的前端源，逗号分隔。公网必须改为真实 HTTPS 域名，不要使用 `*`。 |
| `WEBGIS_AI_DEFAULT_BASEMAP` | 否 | `amap_vector` | 默认底图，可选 `amap_vector`、`amap_imagery`、`amap_light` 或自定义 XYZ 底图配置。 |
| `WEBGIS_AI_AMAP_WEB_SERVICE_KEY` | 按需 | 空 | 高德 Web 服务 key。启用 POI 在线检索时必须配置。 |
| `WEBGIS_AI_AMAP_VECTOR_URL` | 否 | 内置高德矢量 URL | 自定义矢量底图瓦片 URL。 |
| `WEBGIS_AI_AMAP_IMAGERY_URL` | 否 | 内置高德影像 URL | 自定义影像底图瓦片 URL。 |
| `WEBGIS_AI_AMAP_ANNOTATION_URL` | 否 | 内置高德标注 URL | 自定义影像标注瓦片 URL。 |
| `WEBGIS_AI_AMAP_POI_POLYGON_URL` | 否 | `https://restapi.amap.com/v3/place/polygon` | POI 多边形检索接口。 |
| `WEBGIS_AI_OPENWEATHERMAP_API_KEY` | 按需 | 空 | 启用降水、云量、温度、风速和气压五个天气叠加预设。 |
| `WEBGIS_AI_LLM_PROVIDER` | 否 | `minimax` | MiniMax 是当前唯一 LLM provider（Xiaomi MiMo 服务已下线，历史 `mimo` 取值会自动归一为 `minimax`）。 |
| `WEBGIS_AI_MINIMAX_API_KEY` | 按需 | 空 | MiniMax API key。启用 AI 规划能力时配置；不配置时使用规则兜底。 |
| `WEBGIS_AI_MINIMAX_BASE_URL` | 否 | `https://api.minimaxi.com/anthropic` | MiniMax API endpoint，默认走 Anthropic 兼容端点；配置为不含 `/anthropic` 的地址时回退 OpenAI Chat Completions 格式。 |
| `WEBGIS_AI_MINIMAX_MODEL` | 否 | `MiniMax-M2.7-highspeed` | MiniMax 模型名。 |
| `QGIS_ROOT` / `WEBGIS_AI_QGIS_ROOT` | 按需 | 空 | QGIS/OSGeo4W 安装根目录；配置后启动器和后端可派生工作流运行环境。 |
| `WEBGIS_AI_QGIS_PYTHON` | 否 | 自动派生 | 显式指定 QGIS Python；仅在自动识别失败或使用非标准布局时配置。 |
| `WEBGIS_AI_VOICE_ASR_ENABLED` | 否 | `true` | 是否启用后端本地流式 ASR。模型不可用时前端回退浏览器识别或文字输入。 |
| `WEBGIS_AI_VOICE_MODEL_DIR` | 否 | 空 | 直接指定完整语音模型根目录。 |
| `WEBGIS_AI_VOICE_MODEL_STABLE_ROOT` | 否 | 用户缓存目录 | 覆盖跨 worktree 共用的语音模型缓存根目录。 |

默认 `users` 模式不需要访问令牌：首次打开前端进入管理员初始化页创建管理员账号，之后教师可提交注册申请；默认 `approval` 模式必须由管理员审核后才能登录。如需完全关闭公开申请，设置 `WEBGIS_AI_REGISTRATION_MODE=closed`。如需沿用单令牌兼容模式，显式设置 `WEBGIS_AI_AUTH_MODE=legacy_token` 并配置强随机 `WEBGIS_AI_AUTH_TOKEN`。

PowerShell 示例：

```powershell
$env:WEBGIS_AI_AMAP_WEB_SERVICE_KEY="请填入老师自己的高德Web服务Key"
$env:WEBGIS_AI_MINIMAX_API_KEY="请填入老师自己的MiniMax Key"
$env:WEBGIS_AI_CORS_ALLOW_ORIGINS="https://webgis.example.edu"
$env:WEBGIS_AI_COOKIE_SECURE="true"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18999
```

CMD 示例：

```cmd
set WEBGIS_AI_AMAP_WEB_SERVICE_KEY=请填入老师自己的高德Web服务Key
set WEBGIS_AI_MINIMAX_API_KEY=请填入老师自己的MiniMax Key
set WEBGIS_AI_CORS_ALLOW_ORIGINS=https://webgis.example.edu
set WEBGIS_AI_COOKIE_SECURE=true
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18999
```

## 4. 前端配置

前端通过 `VITE_API_BASE_URL` 指向后端 API。Vite 从 `frontend/` 读取环境文件；若不在命令行设置，可把该变量写入 `frontend/.env.local`，不要放在不会被当前配置读取的仓库根目录 `.env`。

默认 `users` 模式下，前端不使用访问令牌：首次打开会进入管理员初始化页或登录页，登录成功后由后端下发 HttpOnly 会话 Cookie（`SameSite=Lax`），后续请求自动携带，无需在前端配置任何令牌。

`legacy_token` 只是后端 API 兼容模式。当前前端普通 HTTP 请求不会读取 `VITE_API_TOKEN`、不会自动附加 Bearer 令牌，也不会把页面 `access_token` 参数传给普通 API；因此不能把现有浏览器 UI 当作 legacy-token 客户端。需要该模式时应使用显式添加 Authorization 的 API 客户端或由可信反向代理完成认证，公网课堂 UI 保持 `users` 模式。

本机发布：

```powershell
cd frontend
$env:VITE_API_BASE_URL="http://127.0.0.1:18999"
npm install
npm run build
npm run preview -- --host 127.0.0.1 --port 5173
```

开发模式：

```powershell
cd frontend
npm install
npm run dev
```

如果前端部署在其他域名或端口，构建前必须设置对应的 `VITE_API_BASE_URL`，否则前端会默认请求 `http://127.0.0.1:18999`。

## 5. 一键启动

本仓库提供 Windows 一键启动脚本：

```powershell
.\start_webgis_ai.cmd
```

该 CMD 入口已经固定向 PowerShell 脚本传入 `-InstallIfMissing -OpenBrowser`，因此首次缺依赖时会自动安装并打开浏览器；不要再次传入这两个开关。

启动器会校验并采用进程或用户环境中的 `WEBGIS_AI_HOST`、`WEBGIS_AI_PORT`。若修改后端端口或允许局域网访问，构建/启动前端前还要把 `VITE_API_BASE_URL` 设置为浏览器实际可访问的后端地址；监听用的 `0.0.0.0` 不能写成客户端访问地址。

如果自动识别 Python 失败，只传入解释器路径：

```powershell
.\start_webgis_ai.cmd -PythonExe "C:\Path\To\Python312\python.exe"
```

若需要控制是否打开浏览器，直接调用 PowerShell 脚本。例如，安装缺失依赖但不自动打开浏览器：

```powershell
.\scripts\start_webgis_ai.ps1 -PythonExe "C:\Path\To\Python312\python.exe" -InstallIfMissing
```

## 6. 发布前安全清单

- 不要提交真实 `WEBGIS_AI_AMAP_WEB_SERVICE_KEY`、`WEBGIS_AI_MINIMAX_API_KEY` 或任何 `.env` 文件。
- 不要提交 `backend/data/` 下的运行产物、上传文件、工作流输出和备份。
- 不要提交 `frontend/dist/`、`*.tsbuildinfo`、`*.log`、`tmp_*.txt` 等构建或调试产物。
- 公网部署必须使用默认 `users` 模式完成管理员初始化与教师登录，并使用 HTTPS；`legacy_token` 兼容模式必须设置强随机 `WEBGIS_AI_AUTH_TOKEN`，避免令牌在明文网络中传输。
- 公网 HTTPS 部署建议设置 `WEBGIS_AI_COOKIE_SECURE=true`；非本机首次初始化管理员必须提供 `WEBGIS_AI_BOOTSTRAP_KEY`。
- 公网部署应明确选择注册策略：允许申请时保持 `approval` 并定期审核；不允许申请时设置 `WEBGIS_AI_REGISTRATION_MODE=closed`。不要在公网使用 `open`。
- 只有在 Cloudflare 或其他可信反向代理会覆盖 `CF-Connecting-IP` 时才设置 `WEBGIS_AI_TRUST_PROXY_HEADERS=true`。
- 公网部署必须设置 `WEBGIS_AI_CORS_ALLOW_ORIGINS` 为真实前端域名，不要使用 `*`。
- 默认 `users` 模式把 `/health` 硬编码为公开路径，且响应会返回本地 workspace、uploads、outputs 路径；`WEBGIS_AI_AUTH_EXEMPT_PATHS` 无法将它改为私有。公网必须在反向代理层限制该路径的外部访问，或在发布前修改服务端响应以移除本机路径。
- 文件上传支持 GeoJSON、CSV、ZIP Shapefile、PNG/JPG 覆盖图。当前未限制上传体积，课堂环境建议由反向代理或网关限制请求体大小。
- MiniMax 异常信息可能包含上游接口返回的错误详情；对外发布时建议在网关或日志策略中避免泄露敏感请求信息。

## 7. 发布验证命令

后端测试：

```powershell
python -m pytest backend/tests -q
```

前端测试：

```powershell
cd frontend
npm test
```

前端生产构建：

```powershell
cd frontend
npm run build
```

公开健康检查：

```powershell
curl http://127.0.0.1:18999/health
```

默认 `users` 模式下，`/llm/status` 需要已登录会话，不能用无 Cookie 的匿名 `curl` 作为成功判据；请在登录后的前端查看服务状态或使用经过认证的测试客户端。

`legacy_token` 兼容模式下的接口自检：

```powershell
curl -H "Authorization: Bearer 请填入访问令牌" http://127.0.0.1:18999/health
curl -H "Authorization: Bearer 请填入访问令牌" http://127.0.0.1:18999/llm/status
```

浏览器验证：

- 打开 `http://127.0.0.1:5173`，首次使用会进入管理员初始化页；之后进入登录页，并按配置显示注册申请入口或关闭状态。
- 确认底图加载、模板切换、图层管理器、数据库面板、智能助教面板可用。
- 配置高德 key 后，测试 POI 检索。
- 配置 MiniMax key 后，测试 AI 助教自然语言请求。

## 8. 已知上线风险

- 当前后端已支持多用户会话登录、管理员/教师分级、审计日志、`X-WebGIS-CSRF` 校验和 CORS 白名单；`legacy_token` 单令牌模式仅作兼容保留。
- `legacy_token` 模式只保留后端兼容；当前浏览器前端不会为普通 API 注入令牌。公网多人使用应保持默认的 `users` 会话登录，或在可信反向代理中实现认证。
- 依赖版本范围较宽，正式长期部署建议锁定 Python 依赖版本并定期做依赖漏洞扫描。
- 大体积课程数据、视频、压缩包不建议放在 GitHub 主仓库，可改用网盘、Release 附件或对象存储分发。
