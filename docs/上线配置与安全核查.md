# WebGIS-AI 上线配置与安全核查

本文档面向协助发布的老师，按当前代码实现整理。发布前请优先参考本文档。

## 1. 项目架构

- 前端：React + TypeScript + Vite + OpenLayers，目录为 `frontend/`。
- 后端：FastAPI，入口为 `backend/app/main.py`。
- 本地运行数据：`backend/data/` 下的 `state/`、`uploads/`、`outputs/`、`workflows/` 属于运行产物，不应提交到 GitHub。
- 内置教学数据：`backend/app/data/builtin/`，属于代码随包资源。
- 默认访问地址：前端 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:18999`。

## 2. 必要运行环境

- Python 3.8 及以上，建议 Python 3.12。
- Node.js 18 及以上，建议 Node.js 20 或 22。
- 可访问在线地图瓦片服务的网络环境。

## 3. 后端配置

生产或课堂发布时，建议通过系统环境变量配置，不要把真实 key 写入代码、文档或 `.env` 后提交。

| 变量名 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `WEBGIS_AI_HOST` | 否 | `127.0.0.1` | 后端监听地址。课堂本机演示保持默认；局域网访问才考虑改为 `0.0.0.0`。 |
| `WEBGIS_AI_PORT` | 否 | `18999` | 后端端口。 |
| `WEBGIS_AI_AUTH_TOKEN` | 公网必填 | 空 | 后端访问令牌。设置后所有 API、文件下载、任务流都需要令牌。 |
| `WEBGIS_AI_AUTH_EXEMPT_PATHS` | 否 | 空 | 免鉴权路径，逗号分隔；公网不建议豁免，内网健康检查可设 `/health`。 |
| `WEBGIS_AI_CORS_ALLOW_ORIGINS` | 公网必填 | `http://127.0.0.1:5173,http://localhost:5173` | 允许访问后端的前端源，逗号分隔。公网必须改为真实 HTTPS 域名，不要使用 `*`。 |
| `WEBGIS_AI_DEFAULT_BASEMAP` | 否 | `amap_vector` | 默认底图，可选 `amap_vector`、`amap_imagery`、`amap_light` 或自定义 XYZ 底图配置。 |
| `WEBGIS_AI_AMAP_WEB_SERVICE_KEY` | 按需 | 空 | 高德 Web 服务 key。启用 POI 在线检索时必须配置。 |
| `WEBGIS_AI_AMAP_VECTOR_URL` | 否 | 内置高德矢量 URL | 自定义矢量底图瓦片 URL。 |
| `WEBGIS_AI_AMAP_IMAGERY_URL` | 否 | 内置高德影像 URL | 自定义影像底图瓦片 URL。 |
| `WEBGIS_AI_AMAP_ANNOTATION_URL` | 否 | 内置高德标注 URL | 自定义影像标注瓦片 URL。 |
| `WEBGIS_AI_AMAP_POI_POLYGON_URL` | 否 | `https://restapi.amap.com/v3/place/polygon` | POI 多边形检索接口。 |
| `WEBGIS_AI_LLM_PROVIDER` | 否 | `minimax` | 当前代码仅完整接入 MiniMax。 |
| `WEBGIS_AI_MINIMAX_API_KEY` | 按需 | 空 | MiniMax API key。启用 AI 规划能力时配置；不配置时使用规则兜底。 |
| `WEBGIS_AI_MINIMAX_BASE_URL` | 否 | `https://api.minimax.io/v1` | MiniMax API endpoint。 |
| `WEBGIS_AI_MINIMAX_MODEL` | 否 | `MiniMax-M2.5` | MiniMax 模型名。 |

PowerShell 示例：

```powershell
$env:WEBGIS_AI_AMAP_WEB_SERVICE_KEY="请填入老师自己的高德Web服务Key"
$env:WEBGIS_AI_MINIMAX_API_KEY="请填入老师自己的MiniMax Key"
$env:WEBGIS_AI_AUTH_TOKEN="请生成至少32位随机访问令牌"
$env:WEBGIS_AI_CORS_ALLOW_ORIGINS="https://webgis.example.edu"
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18999
```

CMD 示例：

```cmd
set WEBGIS_AI_AMAP_WEB_SERVICE_KEY=请填入老师自己的高德Web服务Key
set WEBGIS_AI_MINIMAX_API_KEY=请填入老师自己的MiniMax Key
set WEBGIS_AI_AUTH_TOKEN=请生成至少32位随机访问令牌
set WEBGIS_AI_CORS_ALLOW_ORIGINS=https://webgis.example.edu
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 18999
```

## 4. 前端配置

前端通过 `VITE_API_BASE_URL` 指向后端 API。
如果后端设置了 `WEBGIS_AI_AUTH_TOKEN`，前端请求也必须提供同一个令牌。推荐教师个人演示时在浏览器本地保存令牌，不要把令牌硬编码到公开前端包中；如确需构建时注入，可使用 `VITE_API_TOKEN`，但该值会出现在前端静态资源里，不适合作为多人公网系统的安全边界。

本机发布：

```powershell
cd frontend
$env:VITE_API_BASE_URL="http://127.0.0.1:18999"
npm install
npm run build
npm run preview -- --host 127.0.0.1 --port 5173
```

开发模式：

```powershell
cd frontend
npm install
npm run dev
```

如果前端部署在其他域名或端口，构建前必须设置对应的 `VITE_API_BASE_URL`，否则前端会默认请求 `http://127.0.0.1:18999`。

浏览器本地保存访问令牌：

```javascript
localStorage.setItem("webgis_ai_api_token", "请填入与后端一致的访问令牌");
location.reload();
```

清除令牌：

```javascript
localStorage.removeItem("webgis_ai_api_token");
location.reload();
```

## 5. 一键启动

本仓库提供 Windows 一键启动脚本：

```powershell
.\start_webgis_ai.cmd
```

首次运行缺依赖时可使用：

```powershell
.\start_webgis_ai.cmd -InstallIfMissing -OpenBrowser
```

如果自动识别 Python 失败，显式指定 Python：

```powershell
.\start_webgis_ai.cmd -PythonExe "C:\Users\zcyxn\AppData\Local\Programs\Python\Python312\python.exe" -InstallIfMissing -OpenBrowser
```

## 6. 发布前安全清单

- 不要提交真实 `WEBGIS_AI_AMAP_WEB_SERVICE_KEY`、`WEBGIS_AI_MINIMAX_API_KEY` 或任何 `.env` 文件。
- 不要提交 `backend/data/` 下的运行产物、上传文件、工作流输出和备份。
- 不要提交 `frontend/dist/`、`*.tsbuildinfo`、`*.log`、`tmp_*.txt` 等构建或调试产物。
- 公网部署必须设置 `WEBGIS_AI_AUTH_TOKEN`，并使用 HTTPS，避免令牌在明文网络中传输。
- 公网部署必须设置 `WEBGIS_AI_CORS_ALLOW_ORIGINS` 为真实前端域名，不要使用 `*`。
- `/health` 会返回本地 workspace、uploads、outputs 路径；公网发布前不要设置 `WEBGIS_AI_AUTH_EXEMPT_PATHS=/health`，除非网关层已有访问控制。
- 文件上传支持 GeoJSON、CSV、ZIP Shapefile、PNG/JPG 覆盖图。当前未限制上传体积，课堂环境建议由反向代理或网关限制请求体大小。
- MiniMax 异常信息可能包含上游接口返回的错误详情；对外发布时建议在网关或日志策略中避免泄露敏感请求信息。


前端测试：

- 确认底图加载、模板切换、图层抽屉、智能助教面板可用。

- 配置 MiniMax key 后，测试 AI 助教自然语言请求。

## 8. 已知上线风险

- 当前后端已支持单访问令牌鉴权和 CORS 白名单，但仍不含多用户登录、权限分级、审计日志和 CSRF 防护。
- 前端 `VITE_API_TOKEN` 会被打包进静态资源；公网多人使用时应改为反向代理登录、统一身份认证或后端会话登录。
- 依赖版本范围较宽，正式长期部署建议锁定 Python 依赖版本并定期做依赖漏洞扫描。
- 大体积课程数据、视频、压缩包不建议放在 GitHub 主仓库，可改用网盘、Release 附件或对象存储分发。
