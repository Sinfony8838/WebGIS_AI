## 本轮实现与证据边界

- 追加用户指定的登录页环线修复：允许改 `AuthGlobe.tsx`、`auth.css` 和现有登录组件测试；目标为赤道线与地球共用投影。依赖既有 d3-geo；以倾斜拖动、复位、浅深主题和登录回归验收，不改认证逻辑、账号或其它登录布局。

- 浏览器验收发现结束课堂后缺少新观点的阅读入口；追加 `ReportPanel.tsx` 及其测试，仅在课后显示所选课堂已有 note 记录与来源，不改变报告统计或诊断算法。

- 内置课程升为v6；新引导数据进入开课快照，旧会话继续读取原快照。尚未修改线上课程或生产账号。
- 当前学生任务与教师提示/参考分开；六步手动推进，支持返回、暂停和本环节地图恢复。新中国链不调用模型、语音或QGIS。
- 观点记录是课堂 note 事件，明确区分教师代录、预设示例和教师确认归纳；未写入学生响应或正确率。导航事件仅记录教师操作。
- 地图画线沿用既有地理坐标笔迹，新增按项目的浏览器本机保存；刷新与项目往返可恢复。它不是跨设备云端笔迹同步；重要成果仍可使用原有截图存证。
- 自动化、浏览器、教学来源与真实课堂效果分别记录。没有真实学生参与；演练记录不能作学习达成证明。
