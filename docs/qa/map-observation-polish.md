## 4. 越界发现（只记录复现与建议，未改代码）

### 4.1 三维城市观察截图的底图署名错误（需 App.tsx 接线，交集成负责人）

- **复现**：城市观察激活时 `Map3DGlobe` 将底图瓦片换成 OpenStreetMap
  （`Map3DGlobe.tsx` 中 `urbanSource.format === "geojson"` 分支），但导出说
  明栏写 `底图：高德标准`、`底图署名：© 高德地图`，且建筑颜色图例
  （青绿/蓝/灰）缺失，仅有“当前画面没有专题图例”回退文案。
- **根因**：`App.tsx` `handleStartScreenshot` 的 `freezeDetails` 只读
  `layerState.base_map`，不知道城市观察期间的底图替换。
- **建议最小修改**（约 4 行，`freezeDetails` 内）：当
  `urbanActive && urbanSource?.format === "geojson"` 时改写
  `basemap = "OpenStreetMap 参考底图（三维城市观察）"`、
  `attribution = urbanSource.credit`；可顺带在 `rows` 前部注入三条建筑高度
  颜色图例文本（文案可复用 `UrbanStudyPanel` 第 30 行既有说明）。

### 4.2 画笔激活时笔迹层吞掉右侧工具坞按钮点击（样式层问题）

- **复现**：画笔模式（P）激活时，`.brush-overlay`（`z-index:15`，全视口）
  盖过无 z-index 的右侧工具坞；点击“放大/缩小/重置视角”等按钮不起作用，
  反而在按钮位置画一个墨点（实测 1722→+16px @按钮中心）。深浅主题无关。
- **影响**：标注过程中无法直接使用缩放/重置等工具，需先按 B 退出画笔。
- **建议最小修改**：将 `.right-rail.map-tools-dock`（或工具坞所在层）的
  `z-index` 提到笔迹层之上；涉及 `styles.css`（全局样式）与
  `MapBrushOverlay.tsx`，均不在本任务允许文件内，未修改。

### 4.3 相机 NaN 后产品内无法自愈（健壮性备注）

- 自动化过程中直接调用 Cesium 相机 API 使相机位置变为 NaN 后，区域按钮的
  `flyToBoundingSphere` 无法恢复，只能刷新页面。未找到可触发该状态的产品
  路径，仅作为防御性恢复的待办备注，不属于本轮缺陷。
