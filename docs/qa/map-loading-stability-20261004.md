# 地图加载故障修复与验收（2026-10-04）

## 范围和版本

- 分支：`codex/map-loading-stability`；起点：`92855a88a1ec1ffa948d2c203ea1a9dd1afdd5d7`，创建前已确认与 GitHub main 相同。
- 目标：修复底图失败后被自动持久化为兼容来源、单一来源无请求时限、加载失败缺少恢复入口的问题；缓解公网只读请求的一次性网络失败。
- 允许路径：前端地图加载、恢复提示、只读请求、相关测试与本验收记录。后端源码保持不变。
- 禁止路径：主工作区未提交修改、生产账号、题库、原教案、课堂记录、私有资源和凭据。
- 依赖：既有高德/兼容底图目录、Cesium/OpenLayers；沿用前一轮 PPT 与教师课时改动。

## 诊断证据与边界

1. 最近使用的两个生产项目保存为 `legacy_xyz`，对应 OpenStreetMap。旧逻辑在在线基础瓦片全部失败时，会自动调用切换接口并永久保存兼容底图。
2. 本机直连探测：四个高德影像服务器为 HTTP 200，约 0.27—0.31 秒，高德标准为 HTTP 200、约 0.30 秒；OpenStreetMap 单次直连超时，约 24.2 秒。这是一次网络路径测量，不能据此宣称来源始终不可用；后续隔离浏览器能实际加载 OpenStreetMap。
3. 公网曾返回一次 Cloudflare 530，随后首页与健康请求恢复 200；同轮本地后端和 Caddy 健康为 200。Cloudflared 已使用 HTTP/2、IPv4 与 token 文件，未改动服务配置或凭据。
4. 公网现有浏览器标签的 DOM、截图读取持续超时；本机标签和新隔离标签可正常控制。因此以下浏览器验收明确属于隔离实例，不作为公网浏览器成功的证据。

## 修复后的行为

- 网络失败不再自动改写项目底图；教师自行重试或切换，高德参考图与人口专题数据的来源不混淆。
- 二维多镜像瓦片保留每次 4 秒、至多一个同配置镜像重试；单一来源新增 8 秒时限，失败后释放图片请求。
- 二维、三维首轮底图无成功瓦片时，最迟 12 秒显示失败提示；真实失败可更早提示，真实图片到达才确认可用。
- 提供“重试当前底图”“切换高德标准”按钮；保留业务图层、教师笔迹与当前视野。重试会清理失败来源；切换仍遵守现有接口鉴权。
- 三维替换失败保留上一个可用底图；旧来源异步完成不会把新来源错误标记为已加载。
- 公网 JSON 的 GET 请求遇到网络异常或指定临时服务错误时，延迟 350 毫秒重试一次；POST、PATCH、DELETE、401 和取消请求不重发。

“可用”只表示已有实际瓦片成功，不宣称当前视野全部瓦片或外部服务永远正常。三维使用既有 Cesium 请求调度，12 秒为界面失败提示时限；重试/切换由图层生命周期清理旧来源，不声称为 Cesium 每个请求增加了 8 秒网络时限。
