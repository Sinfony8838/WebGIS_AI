## 行为与范围

- 登录页和主平台首次访问默认浅色，HTML 首屏也声明浅色；已有浏览器主题选择仍保留。
- 新项目的 3D、2D 默认高德影像；已有项目底图和显式环境配置不迁移。
- 底图选择直接消费 PATCH 返回的底图描述，取消随后五个项目相关 GET；重复选择当前底图不请求，等待响应期间禁用选择。
- OpenLayers 按源参数缓存最多八个图层，保留已解码瓦片；失败源和天气源重新选择时重建。隐藏的平面地图暂停图层渲染，显示前先对齐目标视野。
- Cesium 只创建一个初始底图；使用所有配置的瓦片镜像，坐标散列与 OpenLayers 一致，以复用浏览器 HTTP 缓存。替换期间保留上一个底图，完成后释放；取消过时替换和事件监听。
- 多镜像源发生错误时仅重试一个已配置的等价镜像；OpenLayers 每次图片尝试最长四秒，Cesium 使用自身调度与错误回调。失败主机暂避一分钟。仅路径和查询模板一致的镜像可以替换，不改写任意自定义源。
