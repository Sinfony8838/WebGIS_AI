# WebGIS-AI 当前功能说明与课程融合方案

版本日期：2026-05-28
适用对象：地理教育、GIS 教学、教育技术、空间数据分析及相关领域专家

## 一、项目定位

WebGIS-AI 是一个面向地理课堂实时演示与探究式教学的本地 WebGIS 平台，以“全屏地图主舞台 + 悬浮课堂控制台 + 智能助教副驾驶 + GIS 分析工作流”为核心，服务课堂现场读图、讲解、检索、分析和成果导出。

系统的核心价值在于：把地图呈现、教材地图叠加、课堂资料检索、知识讲解、POI 实时检索、数据上传、空间分析与课堂输出统一在同一个浏览器界面中，使教师可以在授课过程中围绕真实空间对象组织观察、提问、解释和验证。

当前版本更适合以下场景：

- 中学地理课堂的大屏演示与读图讲解。
- 高校 GIS、地理信息科学或地理教学法课程中的轻量化 WebGIS 实验。
- 人口地理、区域地理、气候与地形分析、城市公共服务设施分析等专题教学。
- 教师备课阶段的数据整理、图层注册、课堂资料绑定和演示流程预演。

## 二、系统架构与技术基础

### 1. 前端架构

前端采用 React + TypeScript + Vite 构建，地图渲染使用 OpenLayers。主界面以全屏地图为中心，叠加透明悬浮式控制面板，适合课堂投屏和触控屏操作。

主要前端模块包括：

- 地图主画布：承载底图、矢量图层、栅格覆盖层、POI 结果、课堂标注和测距结果。
- 顶部工具栏：提供底图切换、POI 检索、GIS 分析工作流入口、上传数据、导出截图、复位视图等操作。
- 左侧课堂控制台：包含资料搜索、图层列表、POI 检索结果三个分区。
- 右侧工具栏：提供浏览、标注、测距、绘制检索区、清除、缩放等课堂操作。
- 课本地图面板：按主题分类叠加教材或课本地图。
- GIS 分析工作流面板：提交空间分析任务，查看步骤、图例、统计结果和解释文本。
- 智能助教悬浮窗口：支持文本与语音输入，可最小化、拖动和缩放。

### 2. 后端架构

后端采用 FastAPI 提供本地运行时服务，统一管理项目、图层、作业、产物、知识库、工作流和外部服务配置。运行时模型包括：

- project：课堂项目，保存视图、底图、图层、近期操作、启用模板等状态。
- layer：业务图层，支持矢量、栅格、标注、搜索结果、教材地图等类型。
- job：异步任务，用于模板应用、智能助教操作、数据导入和截图导出。
- artifact：课堂产物，如导入文件、截图、讲解稿、统计结果、工作流输出。
- workflow：GIS 分析工作流，包含步骤、依赖、执行状态、产物和错误信息。
- SSE stream：用于向前端实时推送 job 和 workflow 的执行状态。

后端统一持有高德 POI、底图、OpenWeather、MiMo / MiniMax 大模型等服务配置，前端不硬编码服务密钥。

### 3. 数据与目录组织

项目内置数据和运行时数据分离：

- 内置地理数据：`backend/app/data/builtin/`
- 内置知识库：`backend/app/data/builtin/knowledge/`
- 内置课本地图注册表：`backend/app/data/builtin/teaching_maps/registry.json`
- 运行时状态：`backend/data/state/`
- 上传数据：`backend/data/uploads/`
- 输出产物：`backend/data/outputs/`
- 工作流目录：`backend/data/workflows/`

## 三、当前已实现功能

### 1. 全屏 WebGIS 课堂地图

系统以全屏地图作为课堂主舞台，支持多类图层叠加和交互：

- 标准中文底图、影像底图、浅灰底图切换。
- 支持自定义 XYZ 底图。
- 配置 OpenWeatherMap Key 后，可叠加实时天气图层，包括降水、云图、温度、风速和气压。
- 支持矢量 FeatureCollection 图层和图片覆盖图层。
- 支持图层显示 / 隐藏、选择、激活、视图定位、透明度和渲染样式管理。
- 支持地图复位、缩放、要素高亮和选区聚焦。

课堂价值：教师可以围绕“地图作为证据”组织课堂，而不是只展示静态图片。学生可以观察空间格局、区域差异、地理要素叠置关系和尺度变化。

### 2. 课堂交互工具

当前主界面提供适合授课现场使用的轻量交互工具：

- 浏览模式：查看图层、点击要素、定位关联区域。
- 标注模式：在地图指定位置添加课堂标注，标注内容可同步触发助教解释。
- 测距模式：在地图上绘制折线，实时显示长度，适合讲解距离、尺度和空间邻近性。
- 绘区模式：绘制多边形区域，用于后续 POI 区域检索。
- 清除功能：清除当前课堂标注、测距和绘制检索区。
- 快捷键支持：浏览、标注、测距、绘区等模式可用键盘快速切换。

课堂价值：教师可以把“指出来、圈出来、量一量、问一问”变成即时地图操作，增强读图过程的可视化与互动性。

### 3. 底图与实时服务

内置底图包括：

- 高德标准：适合常规区域认知和地名识别。
- 高德影像：适合地貌、城市扩展、海岸、绿洲等影像判读。
- 高德浅灰：适合叠加专题图、课堂标注和统计结果。
- 兼容 XYZ：用于兼容已有单层底图配置。

可选在线服务包括：

- 高德 POI 检索：配置 `WEBGIS_AI_AMAP_WEB_SERVICE_KEY` 后启用。
- OpenWeatherMap 实时天气瓦片：配置 `WEBGIS_AI_OPENWEATHERMAP_API_KEY` 后启用。

课堂价值：底图类型可以随教学目的切换。例如，讲人口空间格局时使用浅灰底图突出专题图；讲地貌和城市形态时切换影像底图；讲气候与天气过程时叠加实时天气图层。

### 4. POI 检索与地图联动

系统支持基于高德 Web Service 的 POI 检索：

- 当前视域检索：按屏幕范围搜索关键词，如“港口”“机场”“学校”“医院”。
- 手绘区域检索：教师先绘制多边形范围，再按区域搜索。
- 结果图层化：检索结果会作为点图层写入地图。
- 结果列表联动：左侧检索列表显示名称、区域、地址，点击后地图定位。
- 结果摘要：智能助教可生成检索结果提示和课堂解释。

课堂价值：适合城市地理、区位因素、交通网络、公共服务设施、商业布局等主题。教师可以把教材中的抽象概念转化为真实地点的空间分布观察。

### 5. 数据上传与坐标系处理

系统支持多种课堂数据导入：

- GeoJSON / JSON：自动识别 GeoJSON CRS 成员，统一转为 EPSG:4326 存储。
- CSV：支持经纬度点数据导入，自动识别常见字段名，如 lat、latitude、y、lon、lng、longitude、x。
- ZIP Shapefile：支持包含 `.shp` 的压缩包导入；如有 `.prj` 文件，会检测坐标系并尝试重投影。
- PNG / JPG：支持图片覆盖层导入，需提供 west、south、east、north 四至范围。

数据处理机制包括：

- 工作坐标系统一为 EPSG:4326。
- 图层元数据保留 source_crs、stored_crs、crs_detection 等信息，便于追溯。
- CSV 若检测出疑似投影坐标米制数值，会给出明确错误提示，避免错误点位静默丢失。
- Shapefile 缺少 `.prj` 时按 EPSG:4326 处理并写入警告。
- ZIP 解压包含路径安全检查，避免目录穿越。

课堂价值：教师和学生可以使用真实数据开展空间表达实验，同时通过 CRS 检测与重投影提示理解 GIS 数据质量和坐标系统的重要性。

### 6. 内置课堂模板

当前内置教学模板包括：

- 通用课堂包：加载欧亚区域框架和课堂关注点，适合区域认知、区位判断和即时读图讲解。
- 人口专题包：一次加载人口分布、人口密度、人口迁移和胡焕庸线对比四类图层。
- 人口分布：基于区域人口数量进行分级设色，突出东密西疏和沿海集聚。
- 人口密度：以点状符号表达密度强弱，适合分析人口集聚中心。
- 人口迁移：以流线表达迁移方向和规模，适合讲解人口流动和区域联系。
- 胡焕庸线对比：叠加经典胡焕庸线与动态拟合线，用于讲解人口空间分界。

模板执行后会写入图层、更新地图视图、登记课堂产物，并保存模板报告。

课堂价值：模板降低了授课准备成本，使教师可以快速进入专题讲解，把时间留给观察、解释和讨论。

### 7. 课本地图叠加

项目内置课本地图注册表，当前可叠加的类别包括：

- 人口：上海人口密度分布图、中国人口分布图（胡焕庸线）、世界人口分布、东北地区人口空间分布、芬兰人口分布等。
- 气候：中国 1 月平均气温分布图、中国 7 月平均气温图、中国年降水量分布图、中国温度带划分图、芬兰降水气温图等。
- 地形：中国地形图、芬兰地形图、东北地区土壤类型分布等。
- 区域：塔里木盆地绿洲与城镇分布、遥感影像等。

每张课本地图带有：

- 地理范围 bounds。
- 推荐视图 center / zoom。
- 默认透明度 opacity。
- 关键词，用于检索或语音指令匹配。

课堂价值：教师可以把教材插图叠加到真实 WebGIS 底图上，比较教材概括图与实际空间背景之间的关系。例如，将“中国年降水量分布图”与地形图或人口分布图叠加，组织学生讨论自然环境与人类活动之间的关联。

### 8. 知识库、资料搜索与课时资料包

系统内置知识库服务，支持：

- 知识条目检索：按关键词、主题、区域、标签筛选。
- 主题统计：人口普查、人口分布、气候区划、课堂数据等主题聚合。
- 图层注册：可将当前课堂图层登记为知识库条目，形成“图层-知识”关联。
- 教学素材管理：可为知识条目上传或链接图片、视频、动画、文档和外部链接。
- 地区绑定：素材可绑定到具体区域、图层、要素或行政代码。
- 课时资料包：可把知识条目或素材导入当前课时，形成授课时可直接调取的资料集合。

左侧“资料搜索”当前会综合检索：

- 本地知识库条目。
- 知识库素材。
- 权威联网入口，例如 NASA Earthdata、USGS、NOAA Climate.gov、World Bank Data、UN Data、FAO Data。

若配置外部资源搜索端点，也可调用自定义联网搜索服务；系统会过滤到 `.gov`、`.edu`、NASA、NOAA、USGS、WMO、FAO、World Bank、UN 等权威域名。

课堂价值：知识库把地图图层、地理概念、教学解释和多媒体资料连接起来。教师点击某一区域时，系统可以根据地区绑定打开相关图文、视频或动画资料，支持“地图点选 - 资料弹出 - 课堂讲解”的流程。

### 9. 智能助教

智能助教是当前项目的核心交互能力之一。前端以可拖动、可缩放、可最小化的悬浮窗口呈现，支持：

- 知识助手模式：回答地理概念、区域地理、地图判读与 GIS 方法问题。
- 工具助手模式：规划并执行 WebGIS 操作，如切换底图、显示图层、应用模板、检索 POI、添加标注、读图讲解等。
- 文本输入和语音输入：语音识别使用浏览器 SpeechRecognition 能力，适合课堂口令式控制。
- 对话记忆：后端保存 conversation、消息记录、运行摘要、任务记忆和地图上下文。
- 引用来源展示：知识型回答可返回引用来源，便于专家审阅和课堂追溯。
- 执行阶段提示：界面显示“理解问题、检索知识库、规划操作、等待确认、执行操作、整理结果”等阶段状态。

当前助教支持的 WebGIS 工具包括：

- 调整地图视角。
- 显示 / 隐藏图层。
- 调整图层顺序。
- 修改图层样式。
- 查询图层要素属性。
- 写入课堂标注。
- 测量和尺度说明。
- 加载课堂模板。
- 导出截图提示。
- 当前视图读图讲解。
- 切换底图。
- POI 检索。
- 叠加或隐藏课本地图。
- 打开课堂素材。

后端具备工具风险评估机制：低风险操作可直接执行，中风险操作标注风险，高风险操作设计为需要确认，未知或不合法工具会被阻断。

### 10. 视觉读图与大模型接入

系统配置层支持两类大模型供应商路径：

- Xiaomi MiMo：当前默认 LLM provider，支持 OpenAI Chat Completions 兼容接口；视觉模型默认可使用 `mimo-v2.5`。
- MiniMax：保留兼容路径，支持 MiniMax Chat Completions 和 MiniMax Token Plan MCP 图片理解。

视觉读图流程为：

1. 前端捕获当前地图截图。
2. 后端保存截图到项目输出目录。
3. 若视觉服务已配置，则调用多模态模型生成课堂读图讲解稿。
4. 若视觉服务未配置或调用失败，则回退到结构化地图上下文读图。

课堂价值：教师可以直接点击“读图讲解”，系统基于当前可视图层和屏幕画面生成面向课堂朗读的讲解文本。该能力适合专家演示，但需要明确说明：视觉读图质量依赖模型配置、截图清晰度和图例信息完整性。

### 11. GIS 分析工作流

系统内置后台 GIS 分析引擎，支持以模板化工作流执行 GIS 分析。前端通过“GIS 分析工作流”面板提交任务，后端通过 SSE 推送实时状态，执行完成后自动把结果 GeoJSON 加载回地图，并展示图例、统计和解释。

当前工作流模板包括：

- 人口密度分级设色图：计算人口密度并按 Jenks、分位数或等距等方法分级设色。
- 设施缓冲区分析：对学校、医院、服务点等要素生成服务范围。
- 胡焕庸线对比分析：结合人口数据计算密度并生成专题统计。
- 区域裁剪分析：将输入图层裁剪到指定区域范围。
- 图层求交集：计算两个图层的几何交集并合并属性。
- 图层空间连接：按空间关系把右侧图层属性连接到左侧要素。
- 字段分级：对数值字段分级并写入新字段。

工作流操作白名单包括：

- load_layer、inspect_layer、reproject、fix_geometries、filter_features。
- calculate_field、buffer、choropleth、aggregate_stats。
- export_geojson、export_style_json、export_map_png。
- clip、intersection、spatial_join、classify。

验证器会检查：

- 工作流 JSON 结构。
- 操作类型是否在白名单内。
- 步骤 id 是否唯一。
- 参数是否齐全。
- 引用关系是否合法。
- CRS、缓冲距离、分级数量、空间连接谓词等参数是否合理。

工作流产物包括：

- GeoJSON 结果图层。
- style.json 分级样式。
- stats.json 统计摘要。
- PNG 地图输出。
- Markdown 结果解释。

课堂价值：该模块把“GIS 分析”从软件菜单操作转化为可解释、可追踪、可复现的课堂任务链。学生不仅能看到结果，还能看到每一步空间处理如何产生证据。

### 12. 截图导出与课堂产物

系统支持地图截图导出，后端将截图保存为 PNG 产物并登记到项目 outputs 中。助教生成的讲解稿、查询摘要、测量说明、POI 摘要、模板报告、工作流统计等也会作为产物保存。

课堂价值：教师可以在课堂结束时导出带有图层、标注和分析结果的截图，用于课堂小结、作业布置、教学反思或教研展示。

## 四、可结合课程使用的方式

### 1. 作为“地图证据驱动”的课堂主屏

适合课程：

- 初高中区域地理、自然地理、人文地理。
- 人口、城市、交通、农业、气候、地形等专题课。
- 地理实践力与综合思维培养课程。

建议流程：

1. 教师加载相关课本地图或内置专题模板。
2. 学生观察空间分布，说出高值区、低值区、过渡区和异常区。
3. 教师使用标注、测距、图层显示隐藏等工具辅助学生形成描述。
4. 助教生成读图讲解稿，教师据此追问“为什么”和“有什么影响”。
5. 导出课堂截图作为本节课的证据链小结。

### 2. 作为 GIS 方法入门实验平台

适合课程：

- 高校 GIS 基础。
- 地理信息技术选修课。
- 地理师范生教学技能课程。

建议流程：

1. 学生上传 GeoJSON、CSV 或 Shapefile。
2. 系统展示坐标系识别、重投影和数据导入结果。
3. 教师讲解 CRS、空间对象、属性表、图层样式等基础概念。
4. 学生提交缓冲区、裁剪、空间连接、分级设色等工作流任务。
5. 通过 workflow steps 和 artifacts 讨论空间分析的输入、处理、输出和误差来源。

### 3. 作为“教材地图 + 真实底图”的对比工具

适合课程：

- 中国地理。
- 世界地理。
- 区域发展案例分析。
- 地图判读训练。

建议流程：

1. 叠加教材地图，如“中国年降水量分布图”或“中国地形图”。
2. 切换高德浅灰或影像底图，观察教材地图和真实空间背景的对应关系。
3. 通过透明度叠加比较河流、地形、城市、人口等要素。
4. 引导学生解释教材地图的概括性、抽象性和尺度限制。
5. 结合知识库材料补充案例资料或权威数据入口。

### 4. 作为智能助教支持的课堂问答系统

适合课程：

- 地理概念讲解。
- 区域差异分析。
- 地图判读训练。
- 教师公开课或教研展示。

建议流程：

1. 教师在助教中输入或语音提出问题，如“解释当前图中人口东密西疏的空间格局”。
2. 系统结合当前地图上下文、可见图层、选中要素和知识库生成回答。
3. 教师把助教回答作为讲解草稿，而不是直接替代教学判断。
4. 对于涉及最新数据或权威结论的问题，优先打开资料搜索中的权威来源核对。

### 5. 作为课前备课与课后沉淀工具

课前可完成：

- 上传本课需要的数据。
- 注册图层到知识库。
- 添加区域绑定素材，如图文、视频、动画、文档和外链。
- 创建当前课时资料包。
- 预演课本地图叠加和分析工作流。

课后可沉淀：

- 导出课堂截图。
- 保留助教讲解稿和分析摘要。
- 保存工作流产物和统计结果。
- 将课堂新图层登记为知识库条目，供后续课程复用。

## 五、示范课程设计

### 课例一：中国人口空间分布与胡焕庸线

适用内容：人口分布、人口密度、人口迁移、自然与社会经济因素综合分析。

建议流程：

1. 加载“人口专题包”，展示人口分布、密度、迁移和胡焕庸线图层。
2. 叠加“中国人口分布图（胡焕庸线）”课本地图。
3. 引导学生描述东南密集、西北稀疏的空间格局。
4. 切换人口密度图层，观察高密度中心与城市群的关系。
5. 切换人口迁移图层，讨论人口流向与区域经济差异。
6. 使用助教生成当前视图读图讲解稿。
7. 运行“人口密度分级设色图”工作流，展示分级方法与统计摘要。
8. 导出课堂截图，作为“人口空间格局证据链”。

可评价问题：

- 为什么胡焕庸线两侧人口分布差异显著？
- 人口密度高值区与地形、气候、经济发展之间有什么关系？
- 人口迁移线条反映了哪些区域联系？

### 课例二：中国气候差异与地形影响

适用内容：气温、降水、地形、季风与区域差异。

建议流程：

1. 叠加“中国 1 月平均气温分布图”和“中国 7 月平均气温图”，比较冬夏差异。
2. 叠加“中国年降水量分布图”，观察东南到西北递减趋势。
3. 叠加“中国地形图”，讨论地形对气温和降水空间格局的影响。
4. 配置天气服务时，可切换实时降水或云图底图，连接课堂知识与当前天气过程。
5. 使用标注工具圈出青藏高原、东部季风区、西北内陆等关键区域。
6. 助教生成面向课堂的讲解稿，并提醒学生区分长期气候图和实时天气图。

可评价问题：

- 为什么 1 月气温南北差异大，而 7 月差异相对小？
- 年降水量为什么从东南沿海向西北内陆递减？
- 地形对气候要素分布有什么影响？

### 课例三：城市公共服务设施与服务范围

适用内容：城市地理、区位选择、公共服务均衡、缓冲区分析。

建议流程：

1. 使用 POI 检索“学校”“医院”或“地铁站”。
2. 在地图上观察设施分布是否集中、均衡或沿交通轴线展开。
3. 学生绘制研究区，使用区域 POI 检索限定范围。
4. 上传设施点数据或使用已有数据，运行“设施缓冲区分析”工作流。
5. 结合统计结果讨论服务覆盖、设施可达性和空间公平。

可评价问题：

- 设施分布是否与人口密集区匹配？
- 缓冲区覆盖不足的区域在哪里？
- 公共服务设施布局还需要哪些数据才能进一步判断？

### 课例四：塔里木盆地绿洲与城镇分布

适用内容：干旱区地理、绿洲农业、城镇空间格局、人地关系。

建议流程：

1. 叠加“塔里木盆地绿洲与城镇分布”课本地图。
2. 切换影像底图，观察绿洲、河流、山前冲积扇和城镇位置。
3. 标注绿洲带和主要城镇，测量绿洲分布尺度。
4. 使用助教解释“水源约束下的城镇空间格局”。
5. 引导学生讨论资源、环境承载力和区域发展方式。

可评价问题：

- 绿洲和城镇为什么多沿盆地边缘分布？
- 水源条件如何影响聚落和农业？
- 干旱区区域发展应注意哪些生态约束？

## 六、面向专家展示的亮点

1. 地图优先：系统不是先生成教案或 PPT，而是把地图作为课堂主界面，强化地理学科的空间思维。
2. 教材图与 WebGIS 融合：支持把教材静态地图作为地理配准后的栅格覆盖层叠加到真实底图上。
3. 数据、知识、素材一体化：知识库条目可以关联图层、区域、素材和课堂资料包。
4. AI 操作受控：智能助教不是直接“自由操作”，而是通过工具白名单、风险评估和后端执行器约束。
5. 工作流可追溯：GIS 分析过程有验证、步骤、产物、统计和解释，适合教学而非黑箱结果展示。
6. 本地运行可控：后端统一管理密钥和状态，前端不暴露服务 Key，适合学校或实验室环境部署。
7. 面向真实课堂：悬浮助教、语音指令、快捷标注、测距、截图导出等设计都服务于教师现场讲解。

## 七、当前边界与后续可扩展方向

项目主线是本地 WebGIS 课堂平台，聚焦地图展示、课堂交互、资料检索、智能助教和 GIS 分析工作流。

需要向专家说明的边界包括：

- POI 检索需要配置高德 Web Service Key。
- 实时天气底图需要配置 OpenWeatherMap Key。
- 大模型与视觉读图需要配置 MiMo 或 MiniMax 相关 Key；未配置时系统会回退到规则或结构化上下文解释。
- GIS 工作流以模板化分析为主，当前更适合教学中常见的标准空间分析，不应承诺完全自由的复杂建模。
- 前端代码中已有 Cesium 3D 数字地球组件和高度 / 缩放换算测试，但当前主界面以 OpenLayers 二维地图为主要课堂入口。
- 知识库编辑组件在代码中保留，当前主界面的核心使用路径是“资料搜索、导入课时、地区素材弹窗”和后端知识库服务。

后续可扩展方向：

- 将更多教材地图标准化注册，覆盖不同年级与章节。
- 建立课程标准、章节、知识点与图层 / 素材 / 工作流的映射。
- 增强学生端任务卡和课堂反馈机制。
- 将工作流结果转化为可评分的探究报告。
- 增强空间统计、网络分析、栅格分析和三维地形展示。
- 建立学校本地知识库与权威数据源同步机制。

## 八、推荐展示话术

可向专家概括为：

WebGIS-AI 当前是一个面向地理课堂的本地 WebGIS 智能教学平台。它以全屏地图为主舞台，把底图切换、教材地图叠加、POI 实时检索、数据上传、课堂标注、测距、知识库资料、智能助教和后台 GIS 分析工作流整合到同一教学界面中。教师可以在授课过程中围绕真实地图组织观察、解释和验证，学生可以通过图层对比、区域检索和空间分析理解地理事物的分布特征、形成机制与区域差异。系统强调 AI 辅助但不放弃 GIS 过程的可追溯性：助教操作受工具白名单和风险评估约束，分析结果保留步骤、统计、样式和输出产物，适合用于课堂展示、GIS 入门实验和地理教学研究。
