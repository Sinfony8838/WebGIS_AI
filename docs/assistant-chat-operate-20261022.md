## 最终交互

- Chat 负责知识问答、读图、生图；Operate 使用真实项目操作能力，不能生图或隐式创建教案。
- 只有顶部 Chat / Operate 切换；消息下无转发模式按钮。顶部助教显示现有吉祥物，主界面仍显示 GeoBot。
- 历史按钮打开当前模式侧栏，顶部新建会话。展开面板时为左右布局，紧凑状态为侧栏抽屉。
- 历史按用户、项目、模式筛选，读取服务器消息和任务结果；恢复失败结果；读取历史不会重放 UI 动作。
- 执行中显示真实阶段，支持展开工具过程；完成后显示“用时”及总结。底部不显示调用记录或 token。后台仍保留审计用量。
- 语音与模式解耦。单击开始、再击结束发送；700ms 内三击长时通话，菜单有等价入口；队列上限 3；挂断清空队列、停止收音播报，已启动任务继续；明确取消才停止任务。重连不能延长 15 分钟前端总时限。

## 架构与接口

- `assistant_profiles.py`：模式别名、会话绑定、工具权限；`chat_assistant.py`：独立 Chat；现有 `interaction_agent.py`：Operate 行动与观察循环。
- `InteractionRun`：每回合最多 3 次模型请求，失败也计数；活动时间线和用量；取消贯穿执行和网络响应。工作流最多 8 步。
- `/assistant/messages`、Job/SSE、UI observations 保持兼容；新增当前项目 `/assistant/conversations?mode=chat|operate` 列表；单会话接口增加只读执行摘要。
- `create_measurement` / `generate_profile` / `compare_profiles` 使用已有测距地图实现及采样器，创建带作用域的服务器结果。前端展示同一份数据并回执实际应用结果。
- 文本模型统一 `MiniMax-M3.1-Flash`，旧 MiniMax-M2 配置迁移到新默认；官方 `api.minimax.cn`，低推理强度、4096 输出上限。图片服务保留独立图片模型。
- 参考设计：DeepSeek Harness 工具注册与约束、Pi 会话事件及取消；没有引入这两个框架的运行依赖。

## 固定演示流程

1. 打开助教，展开面板和历史侧栏。展示新建会话入口，确认顶部主品牌仍为 GeoBot。
2. Chat 新建会话，询问“人口密度与地形通常有什么关系？简洁回答”。观察真实回答阶段和完成用时。
3. 顶部切换 Operate，在侧栏新建会话。先说/输入“放大”，明确快捷执行为零模型请求。
4. 输入完整指令：“使用测距工具连接北京和上海，生成人口密度沿线变化折线图，再叠加地形曲线，分析两者的关系。”
5. 观察创建测线、人口采样、地形采样、叠加曲线与结果核对。完成后展开“用时”查看步骤。
6. 收起面板或侧栏观察双轴图，移动到图表查看两项数值和地图位置；展开来源，说明真实缓存、年份与11个缺失点。
7. 打开历史中的另一会话再返回，说明恢复的是内容与结果，不会重画测线；刷新后仍可读取历史。
8. 语音设备验收完成后再演示单击录音/三连击通话/打断播报/排队/挂断。未验证的真实麦克风不纳入当前成功演示承诺。

## Chat 回答抽查及边界

共抽查8类问题：单位换算、总量与密度、海拔相关/因果、单年GPW与多年趋势、实时人口、地图越权、教案发布越权、索取内部提示与思考。模型真实请求和确定性边界回复分别记录。

第一轮发现人口密度充分/必要条件混淆、过时人口数冒充最新、GPW方法泛化错误和教案错误指向Operate。已加入比率/因果约束、GPW项目事实依据；无实时统计工具时明确不能核验最新人数；教案创建发布指向独立入口。

复测：单位为100万平方米；总量不能单独决定密度；GPW2020剖面不表示2020—2025增长；实时数值请求不编数；地图及教案请求不执行；提示注入没有泄露系统提示、内部思考或执行工具。8项均无越权动作。4项使用模型，4项为代码边界回复。

**仍保留内容质量风险**：因果问题虽然明确“相关不等于因果”，但复测仍出现“海拔通过坡度影响人口”的不严谨措辞。没有将这项记作完全准确，也没有把有限样本等同于通用问答准确率；正式课堂需教师核对。记录：`chat-accuracy-final.json`、`chat-causality-recheck.json`。

GPW方法核对：[NASA/SEDAC GPWv4.11目录](https://catalog.data.gov/dataset/gridded-population-of-the-world-version-4-gpwv4-population-density-revision-11)。人口年份口径核对：[上海统计局2024统计公报](https://tjj.sh.gov.cn/tjgb/20250324/a7fe18c6d5c24d66bfca89c5bb4cdcfb.html)。
