# 《人口分布》课前备课—40分钟课堂—课后巩固全流程演示脚本

> 更新日期：2026-09-04  
> 适用对象：高中地理教师、教研员、项目评审  
> 使用课时：lesson_builtin_population_distribution《人口分布：中国人口的空间格局与胡焕庸线》

## 一、时间边界

本案例由三个连续但计时独立的部分组成：

1. **课前备课：**教师与智能体分步共创教案、审核地图能力并预演，不占用课堂40分钟。
2. **正式课堂：**系统根据课前生成并确认的教案完整上课，严格40分钟；最后5分钟包含课堂当堂复盘和即时巩固。
3. **课后复盘：**下课后依据真实课堂记录生成报告，并推荐分层练习巩固，不计入课堂40分钟。

因此，“40分钟”只约束正式上课过程，不约束课前教案设计和课后练习推荐。若用于产品展示，应完整展示三段流程；不能把备课和课后报告压进40分钟课堂。

## 二、教学案例设定

- 年级与模块：高一地理必修第二册。
- 课题：人口分布——中国人口空间格局与胡焕庸线。
- 学情：学生已接触人口密度，但容易混淆人口总量、人口密度与实时人口；会背“东南多、西北少”，却缺少地图证据和机制解释。
- 核心问题：为什么黑河—腾冲线能够长期概括中国人口分布的基本格局？
- 学习主线：审查指标与尺度 → 描述格局 → 寻找分界和例外 → 组织自然与人文证据 → 完成尺度迁移。
- 教师端边界：口头提问由教师依据现场回答记录“答对/部分/误区”；未采集学生端作答时，不展示虚构票数、正确率或全班掌握度。

## 三、课前备课演示：智能体分步共创

### 3.1 演示目标

课前环节最终必须产出一份**可在课堂控制台直接执行、环节合计40分钟**的教案，而不是只生成一篇文字稿。

### 3.2 教师输入

进入“共创教案”，输入：

> 高一必修二《人口分布》，正式上课时间40分钟。学生已经学过人口密度，但容易把人口总量、人口密度和实时人口混为一谈。请围绕胡焕庸线，用地图证据引导学生先观察再解释，安排一次Top20数据探究、一次上海尺度迁移，并在课堂最后5分钟完成当堂复盘和即时巩固。下课后还要根据课堂记录推荐练习。请先确认需求，再分步与我共创，不要一次生成全部教案。

系统应识别：

- 课题：人口分布；
- 年级：高一；
- 课堂时长：40分钟；
- 学情、地图证据、Top20、尺度迁移、当堂复盘和课后练习均保存为教学约束，而不能被拼接进课题标题。

### 3.3 七步引导路径

| 步骤 | 智能体应怎样引导 | 教师审核点 | 通过后产出 |
| --- | --- | --- | --- |
| 1. 教学需求 | 复述课题、年级、40分钟及学情，询问是否准确 | 课前备课与课堂40分钟是否分开 | 需求约束 |
| 2. 课标、教材与学情 | 提示教师确认课程要求、已有基础和主要误区 | 是否突出“运用资料描述与解释” | 课标与学情分析 |
| 3. 目标与重难点 | 使用“描述、引用、解释、迁移”等可观察动词 | 目标能否在课堂中被提问或观察 | 教学目标与成功标准 |
| 4. 40分钟教学过程 | 生成8个环节并自动核对总时长 | 必须合计40分钟，最后5分钟用于当堂复盘 | 可执行时间轴 |
| 5. GIS/AI能力绑定 | 给环节绑定Top20、2D/3D、专题图、观察、截图 | 所有能力必须是真实可用功能 | 地图场景与操作 |
| 6. 课堂预演 | 检查图层、镜头、题目、时长和数据边界 | 3D后回二维；一次只聚焦一类证据 | 预演检查结果 |
| 7. 教师确认保存 | 展示差异，允许接受、修改或直接编辑 | 教师拥有最终确认权 | 正式40分钟课时 |

演示时必须让观众看见“接受本节、提出修改、直接编辑”三种教师决策入口。智能体负责提议和提醒，不能绕过教师确认直接替换正式教案。

### 3.4 课前预演清单

- 8个环节时长依次为3、4、5、7、8、8、3、2分钟，总计40分钟。
- Top20使用2020年地级市常住人口总量，不解释为人口密度排名。
- 胡焕庸线3D画面只用于宏观空间感，规范判读回到二维。
- 影响因素图按气候、地形、河流、经济逐张聚焦，避免堆叠。
- 上海区县图能够完成全国尺度向城市内部尺度迁移。
- 最后5分钟明确命名为“当堂复盘”和“当堂巩固”。
- 课堂结束后报告能输出真实记录和课后推荐练习。

## 四、正式课堂：严格40分钟

| 课堂时间 | 环节 | 用时 | 系统功能 | 教学任务 |
| --- | --- | ---: | --- | --- |
| 00:00–03:00 | s1 问题导入：人口分布均匀吗 | 3分钟 | 二维人口分布图、知识卡 | 观察并描述总体格局 |
| 03:00–07:00 | s2 概念建构：人口分布与人口密度 | 4分钟 | 人口密度图、口头题 | 区分总量、密度和实时人口 |
| 07:00–12:00 | s3 数据探究：2020年地级市人口Top20 | 5分钟 | Top20查询、排名弹窗、教师观察 | 识别总量集聚并审查指标 |
| 12:00–19:00 | s4 中国主案例：胡焕庸线两侧差异 | 7分钟 | 3D地球、胡焕庸线、二维专题图 | 描述分界、差异和局地例外 |
| 19:00–27:00 | s5 影响因素归纳 | 8分钟 | 气候、地形、河流、经济图层 | 构建因素—证据—机制链 |
| 27:00–35:00 | s6 上海区县尺度迁移 | 8分钟 | 上海人口密度专题图 | 认识尺度变化与主导因素变化 |
| 35:00–38:00 | s7 当堂复盘：证据链定格 | 3分钟 | 全国视图、知识卡、截图存证 | 学生口述完整证据链 |
| 38:00–40:00 | s8 当堂巩固：四步法检测 | 2分钟 | 教师口头选择题、学情速记 | 检查方法能否当堂调用 |

**总计：40分钟。**

### s1　问题导入（3分钟）

教师一键应用人口分布场景，暂不显示胡焕庸线。

提问：

> 如果人口均匀分布，图面颜色应呈现什么特点？当前地图实际表现出怎样的方向性差异？

收束：

> 中国人口分布明显不均，总体东南部较稠密、西北部较稀疏；下一步必须用指标和地图证据把这句话说完整。

### s2　概念建构（4分钟）

切换人口密度图，展示计算题：

> 甲地人口500万、面积50万平方千米；乙地人口300万、面积10万平方千米。哪一地人口更稠密？

答案：甲地10人/平方千米，乙地30人/平方千米。人口总量大不代表人口密度一定高。实时人口则是某一时点的动态估计，三类指标不得混用。

### s3　Top20数据探究（5分钟）

进入s3，等待地图高亮和排名弹窗加载完成。

提问：

> Top20城市主要位于胡焕庸线哪一侧？这项结果能否单独证明这些城市的人口密度最高？

学生先观察，教师点击“口头提问”，再依据现场回答记录“答对/部分/误区”。

收束：

> Top20说明人口总量向大型城市和城市群节点集聚，但行政范围和城市规模都会影响总量，因此还要与人口密度图交叉验证。

### s4　胡焕庸线主案例（7分钟）

1. 用3D画面约40—60秒建立全国空间感。
2. 切回二维专题图完成正式判读。
3. 定位黑河与腾冲，观察线两侧的总体差异和西北河谷、绿洲等例外。

可向助教发送：

> 只用一句可直接口播的话，结合当前二维画面解释胡焕庸线表达的空间格局；不要补充画面中没有的数字。

收束：

> 胡焕庸线是概括宏观差异的地理分界，不是行政边界，也不意味着线西北侧无人。

### s5　影响因素归纳（8分钟）

保持二维，按“气候→地形→河流→经济”逐图切换。每张图只完成一条“因素—位置证据—作用机制—人口结果”表达。

- 气候：东南水热条件较好；西北干旱、青藏高寒。
- 地形：东部低平地区更利于农业、交通和城市建设。
- 河流：西北人口常沿河谷和绿洲呈点状、带状集聚。
- 经济：就业、交通和公共服务进一步强化城市节点集聚。

收束：

> 自然条件构成基础约束，人文因素能够强化或重塑局部格局；不能只罗列因素名称，也不能用单一因素解释全部现象。

### s6　上海尺度迁移（8分钟）

飞至上海并聚焦shanghai_population_density。

提问：

> 为什么黄浦与崇明的人口密度差异，不能主要用全国尺度的气候差异来解释？

收束：

> 全国尺度突出自然基础和长期开发；城市内部尺度更多受城市功能、交通、土地利用、公共服务和规划影响。分析框架可以迁移，主导因素会随尺度变化。

### s7　课堂当堂复盘（3分钟）

回到全国人口密度与胡焕庸线场景。要求学生脱离零散问题，用完整证据链复述：

> 中国人口分布总体东南稠密、西北稀疏，胡焕庸线概括了这一宏观差异。东南部水热条件较好、地形较低平，经济与交通进一步促进人口集聚；西北部整体稀疏，但河谷、绿洲和城市节点仍有局地集聚。

教师根据复述记录一次课堂观察，并框选地图完成“截图存证”。这一环节是**课堂内的当堂复盘**，仍属于40分钟课时。

### s8　课堂当堂巩固（2分钟）

教师口头呈现“四步法”选择题：

> 哪个表述同时包含指标与尺度、总体格局、分界或例外、自然与人文解释？

学生口头选择并说明理由，教师记录“答对/部分/误区”。最后定格方法：

> 看指标与尺度 → 描述总体与高低值 → 找分界与例外 → 用自然和人文证据解释。

40分钟到点后点击“结束上课”，不在课堂内继续生成报告或布置长练习。

## 五、课后复盘与推荐练习：课堂结束后进行

### 5.1 课堂报告

进入“课后”，选择刚结束的课堂，点击“生成课堂报告”。报告应展示：

- 实际课堂时长和各环节计划/实际用时；
- 教师口头提问记录；
- 教师观察中的答对、部分和误区计数；
- 明确记录的误区标签与备注；
- 课堂截图数量；
- 学生端作答是否真实采集；
- 基于上述证据的教学诊断。

如果学生端作答未采集，系统必须明确写“未采集”，不能生成票数、正确率、“最易错题”或“全班普遍掌握/未掌握”等结论。

### 5.2 课后推荐练习巩固

报告下方独立显示“课后推荐练习巩固”，并标注“课堂结束后，不计入40分钟课时”。本案例推荐三题：

| 层级 | 练习 | 建议时间 | 巩固目标 |
| --- | --- | ---: | --- |
| 基础必做 | 人口总量与人口密度辨析 | 6分钟 | 修正指标混淆，完成密度计算 |
| 核心必做 | 胡焕庸线地图证据链 | 8分钟 | 用80—120字完成四步表达 |
| 迁移选做 | 上海城市内部尺度迁移 | 6分钟 | 解释尺度变化与主导因素变化 |

每道题必须同时给出题目、答案要点、建议用时和推荐依据。推荐依据遵守以下规则：

- 有学生端作答时，可依据真实最低正确率题推荐同类变式。
- 没有学生端作答但有明确误区标签时，只依据教师记录的误区推荐。
- 只有“部分正确”而没有内容备注时，只能推荐核心目标复测，不能宣称已经发现某个全班共性误区。
- 完全缺少学情证据时，明确标注为依据教案目标生成的通用巩固题。

### 5.3 教师继续与智能体复盘

可输入：

> 只依据本次课堂真实记录，说明哪些教学结论有证据、哪些不能判断；再从推荐练习中选出最适合作为必做题的一题，并说明理由。

智能体应先说明数据边界，再引用真实记录，不得把课后练习本身反过来当成已经发生的学生表现。

## 六、演示操作顺序

1. 课前打开“共创教案”，用教师原话展示七步引导和40分钟校验。
2. 保存或选择确认后的《人口分布》正式课时。
3. 点击“开始上课”，按8个环节完整演示40分钟课堂。
4. 在s7完成当堂复盘和截图，在s8完成即时巩固。
5. 40分钟结束后点击“结束上课”。
6. 再进入“课后”生成报告，展示证据边界。
7. 展示三层课后练习及其推荐依据。
8. 用智能体完成一次基于真实记录的教师复盘。

## 七、现场异常处理

| 情况 | 正确处理 |
| --- | --- |
| 备课智能体超过60秒未返回 | 使用直接编辑和接受本节继续审核；课前等待不挤占课堂40分钟 |
| 3D镜头不利于读图 | 立即切回二维，不在3D画面做精确判读 |
| 图层仍在加载 | 等待按钮恢复后再切下一环节，避免产生重复环节记录 |
| 截图后提示与图片库不同步 | 等图片库出现新图并确认课堂snapshot事件后继续 |
| 学生端未参与 | 只展示教师观察和“未采集”，不演示虚构统计 |
| 课堂会话中途暂停 | 课后报告先核对暂停时间，再判断是否属于真实教学超时 |

## 八、验收标准

- 课前智能体正确识别“人口分布、高一、40分钟”，并分七步引导教师审核。
- 正式教案8个环节合计严格40分钟。
- s7、s8在40分钟内承担当堂复盘和即时巩固。
- 课堂结束后才能进入报告与推荐练习。
- 课后报告准确区分学生端作答和教师观察。
- 报告提供基础必做、核心必做、迁移选做三类练习。
- 每道推荐练习有题目、答案要点、建议用时和证据边界。
- 无学生作答数据时，系统不推断正确率、最易错题或全班掌握情况。
